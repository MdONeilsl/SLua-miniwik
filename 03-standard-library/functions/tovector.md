# `tovector`

```lua
tovector(val: string? | vector) -> vector?
```

The function transforms an input string into a vector data structure. If the provided input cannot be successfully converted, it yields `nil`.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `string? | vector` | The input string intended for conversion into a vector. |

**Returns:** `vector?`
