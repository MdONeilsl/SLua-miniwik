# `unpack`

```lua
unpack(tab: {V}, i: number?, j: number?) -> ...V
```

This function retrieves elements stored within a given collection based on defined position boundaries.

## Arguments

| Name | Type | Description |
|---|---|---|
| `tab` | `{V}` | The array containing the data to be pulled out. |
| `i` | `number?` | The index where extraction begins. |
| `j` | `number?` | The final position for the extracted data. |

**Returns:** `...V`
