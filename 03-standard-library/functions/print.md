# `print`

```lua
print(...) -> ()
```

This function transmits all provided arguments as text messages directly to the object's owner. These messages are separated by four spaces, and reception requires the owner to be in the same region.

## Arguments

| Name | Type | Description |
|---|---|---|
| `...` | `T...` | The values that will be transmitted as text messages to the owner. |

**Returns:** `()`
