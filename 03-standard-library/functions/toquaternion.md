# `toquaternion`

```lua
toquaternion(value: string? | quaternion) -> quaternion?
```

Converts an input string representation into a quaternion data type. It yields nil when the provided value cannot be processed.

## Arguments

| Name | Type | Description |
|---|---|---|
| `value` | `string? | quaternion` | The input string intended for quaternion conversion. |

**Returns:** `quaternion?`
