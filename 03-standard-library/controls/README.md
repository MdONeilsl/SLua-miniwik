# controls

This folder contains fundamental control flow keywords and statements used for structuring logic in SLua code.

| Path | Contents |
|---|---|
| [and](and.md) | Logical conjunction operator 'and' |
| [break](break.md) | Exits the nearest loop structure |
| [const](const.md) | Declares local constant variable or function |
| [continue](continue.md) | Skips to next loop iteration step |
| [do](do.md) | Defines a block of code execution |
| [else](else.md) | Alternative branch in if/else statement |
| [elseif](elseif.md) | Additional conditional branch for if statements |
| [end](end.md) | Closes control structures like loops and functions |
| [export](export.md) | Declares type usable outside module |
| [for](for.md) | Iterates using numeric, generic, or table loop |
| [function](function.md) | Defines a new executable function block |
| [if](if.md) | Executes code based on condition check |
| [in](in.md) | Used to iterate over collection elements |
| [local](local.md) | Declares variable or function scope locally |
| [not](not.md) | Performs logical negation operation |
| [or](or.md) | Logical disjunction operator 'or' |
| [read](read.md) | Marks a type field as read-only data |
| [repeat](repeat.md) | Executes code until condition becomes true |
| [return](return.md) | Exits function and returns specified value |
| [then](then.md) | Introduces block executed when condition is true |
| [until](until.md) | Terminates repeat loop by testing condition |
| [while](while.md) | Repeats code as long as condition holds |
| [write](write.md) | Marks a type field as write-only data |
