# `table.append`

```lua
table.append(a: {V}, ...) -> ()
```

This function adds multiple items onto the tail end of a given table structure, increasing its size by adding new elements sequentially.

## Arguments

| Name | Type | Description |
|---|---|---|
| `a` | `{V}` | The table receiving the appended elements. |
| `...` | `...V` | One or more values to be added to the table. |

**Returns:** `()`
