# `table.getn`

```lua
table.getn(a: {any}) -> number
```

Returns the count of elements in the given array, though this function is now deprecated—use the `#` operator instead.

## Arguments

| Name | Type | Description |
|---|---|---|
| `a` | `{any}` | Checks the length of this array-like table. |

**Returns:** `number`
