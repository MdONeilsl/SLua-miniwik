# `table.isfrozen`

```lua
table.isfrozen(t: {}) -> boolean
```

This function determines whether a given table object has been marked as immutable. It returns true if the structure cannot be modified and false otherwise.

## Arguments

| Name | Type | Description |
|---|---|---|
| `t` | `{}` | The structure whose frozen status is being evaluated. |

**Returns:** `boolean`
