# `vector.abs`

```lua
vector.abs(vec: vector) -> vector
```

This function calculates the absolute value for every component within the given vector. It effectively applies the math.abs operation across all elements of the input vector.

## Arguments

| Name | Type | Description |
|---|---|---|
| `vec` | `vector` | The input vector whose components will have their absolute values calculated. |

**Returns:** `vector`
