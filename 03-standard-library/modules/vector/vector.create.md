# `vector.create`

```lua
vector.create(x: number, y: number, z: number?) -> vector
```

Creates a new vector using the specified component values.

## Arguments

| Name | Type | Description |
|---|---|---|
| `x` | `number` | Specifies the horizontal component value. |
| `y` | `number` | Specifies the vertical component value. |
| `z` | `number?` | Optional depth component value. |

**Returns:** `vector`
