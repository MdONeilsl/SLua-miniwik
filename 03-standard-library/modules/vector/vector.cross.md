# `vector.cross`

```lua
vector.cross(start_vec: vector, end_vec: vector) -> vector
```

Computes the mathematical cross product result given two vector inputs.

## Arguments

| Name | Type | Description |
|---|---|---|
| `start_vec` | `vector` | The initial vector used for the calculation. |
| `end_vec` | `vector` | The second vector involved in the cross product. |

**Returns:** `vector`
