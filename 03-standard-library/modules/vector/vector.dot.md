# `vector.dot`

```lua
vector.dot(vec1: vector, vec2: vector) -> number
```

Computes the scalar product of two vectors by multiplying corresponding components and summing the results.

## Arguments

| Name | Type | Description |
|---|---|---|
| `vec1` | `vector` | First vector operand for the dot product. |
| `vec2` | `vector` | Second vector operand for the dot product. |

**Returns:** `number`
