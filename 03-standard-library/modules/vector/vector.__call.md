# `vector.__call`

```lua
vector(x: number, y: number, z: number?) -> vector
```

Calling this function generates a fresh vector using the provided components. This behavior mirrors calling `vector.create()`.

## Arguments

| Name | Type | Description |
|---|---|---|
| `x` | `number` | The first coordinate value for the vector. |
| `y` | `number` | The second coordinate value for the vector. |
| `z` | `number?` | The third coordinate value for the vector. |

**Returns:** `vector`
