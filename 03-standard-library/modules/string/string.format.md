# `string.format`

```lua
string.format(format_string: string, ...) -> string
```

This function constructs a formatted text output by substituting provided arguments into placeholders defined within the format string, following printf conventions.

## Arguments

| Name | Type | Description |
|---|---|---|
| `format_string` | `string` | The template containing format specifiers. |
| `...` | `...any` | Data items that will be inserted into the string. |

**Returns:** `string`
