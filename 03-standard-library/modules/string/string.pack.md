# `string.pack`

```lua
string.pack(format_string: string, ...) -> string
```

This function constructs a binary string by converting provided values according to the specifications given in the format string.

## Arguments

| Name | Type | Description |
|---|---|---|
| `format_string` | `string` | Specifies how values should be formatted for packing. |
| `...` | `...any` | The data items that need conversion into the string format. |

**Returns:** `string`
