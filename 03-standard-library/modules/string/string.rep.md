# `string.rep`

```lua
string.rep(src: string, count: number) -> string
```

Repeats the given string a specified number of times, returning an empty string if the repetition count is zero or less.

## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `string` | String to be duplicated in sequence. |
| `count` | `number` | How many times to duplicate the input string. |

**Returns:** `string`
