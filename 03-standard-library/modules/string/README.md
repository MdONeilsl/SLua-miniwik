# string

This module provides comprehensive functions for manipulating and analyzing Lua strings in detail.

| Path | Contents |
|---|---|
| [byte](string.byte.md) | Byte codes within specified index range |
| [char](string.char.md) | Creates string from given byte integers |
| [find](string.find.md) | Find start and end indices of pattern |
| [format](string.format.md) | Format values into strings with specifiers |
| [gmatch](string.gmatch.md) | Iterate over all occurrences of pattern |
| [gsub](string.gsub.md) | Replace multiple pattern occurrences in string |
| [len](string.len.md) | Get total number of bytes in string |
| [lower](string.lower.md) | Converts string to lowercase ASCII characters |
| [match](string.match.md) | Find all matches using regular expression |
| [pack](string.pack.md) | Pack various values into binary string |
| [packsize](string.packsize.md) | Calculate size of packed string format |
| [rep](string.rep.md) | Repeat specified string a given number |
| [reverse](string.reverse.md) | Returns reversed copy of string bytes |
| [split](string.split.md) | Split string into substrings using separator |
| [sub](string.sub.md) | Extract substring from specified byte range |
| [unpack](string.unpack.md) | Decode binary string using a format |
| [upper](string.upper.md) | Converts string to uppercase ASCII characters |
