# `math.noise`

```lua
math.noise(x: number, y: number?, z: number?) -> number
```

Computes a Perlin noise value at the specified 3D point, yielding a result between -1.0 and 1.0.

## Arguments

| Name | Type | Description |
|---|---|---|
| `x` | `number` | Specifies the horizontal position for noise evaluation. |
| `y` | `number?` | Specifies the vertical position for noise evaluation. |
| `z` | `number?` | Specifies the depth position for noise evaluation. |

**Returns:** `number`
