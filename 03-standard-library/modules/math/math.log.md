# `math.log`

```lua
math.log(val: number, base: number?) -> number
```

Computes the logarithm of `val` using the specified `base`; if `base` is omitted, uses the natural logarithm (base e).

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Value whose logarithm is to be calculated. |
| `base` | `number?` | Radix for the logarithmic computation; defaults to e if not provided. |

**Returns:** `number`
