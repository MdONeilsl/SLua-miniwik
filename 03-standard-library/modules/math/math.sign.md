# `math.sign`

```lua
math.sign(val: number) -> number
```

Determines the mathematical sign of a given number. It returns -1 if the input is negative, 1 if it is positive, and 0 when the value equals zero.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | The numerical value for which the sign must be determined. |

**Returns:** `number`
