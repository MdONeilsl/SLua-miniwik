# `math.atan2`

```lua
math.atan2(y: number, x: number) -> number
```

Computes the angle in radians between the positive x-axis and the point (x, y), determining the correct quadrant based on the signs of both coordinates.

## Arguments

| Name | Type | Description |
|---|---|---|
| `y` | `number` | Vertical coordinate for angle calculation. |
| `x` | `number` | Horizontal coordinate for angle calculation. |

**Returns:** `number`
