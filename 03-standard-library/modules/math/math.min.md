# `math.min`

```lua
math.min(val: number, ...) -> number
```

The function identifies the smallest value among all provided numeric inputs.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | First number to compare for the smallest value. |
| `...` | `...number` | Additional numbers to include in the minimum comparison. |

**Returns:** `number`
