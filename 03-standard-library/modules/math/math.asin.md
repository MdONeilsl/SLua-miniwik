# `math.asin`

```lua
math.asin(val: number) -> number
```

Computes the inverse sine of val, yielding the result in radians. If val falls outside the interval [-1.0, 1.0], it returns NaN.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | The value, constrained between -1.0 and 1.0, whose inverse sine is calculated. |

**Returns:** `number`
