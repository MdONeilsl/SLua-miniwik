# `math.max`

```lua
math.max(val: number, ...) -> number
```

The function identifies the largest value among the provided numeric inputs.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | First number to compare for the maximum. |
| `...` | `...number` | Additional numbers to include in the maximum search. |

**Returns:** `number`
