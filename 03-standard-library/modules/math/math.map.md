# `math.map`

```lua
math.map(val: number, inMin: number, inMax: number, outMin: number, outMax: number) -> number
```

Transforms a value from one numerical range to another, scaling it proportionally.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Value to be transformed across ranges. |
| `inMin` | `number` | Minimum value of the source range. |
| `inMax` | `number` | Maximum value of the source range. |
| `outMin` | `number` | Minimum value of the target range. |
| `outMax` | `number` | Maximum value of the target range. |

**Returns:** `number`
