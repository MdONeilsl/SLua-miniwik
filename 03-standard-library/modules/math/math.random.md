# `math.random`

```lua
math.random(min: number?, max: number?) -> number
```

Generates a pseudorandom floating-point number within the specified inclusive range, or between 0 and 1 if no arguments are provided.

## Arguments

| Name | Type | Description |
|---|---|---|
| `min` | `number?` | Lower bound of the interval to sample from. |
| `max` | `number?` | Upper bound of the interval to sample from. |

**Returns:** `number`
