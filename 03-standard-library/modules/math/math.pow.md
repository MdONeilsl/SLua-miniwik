# `math.pow`

```lua
math.pow(base: number, exponent: number) -> number
```

Calculates the result of raising a base number to the specified power.

## Arguments

| Name | Type | Description |
|---|---|---|
| `base` | `number` | The initial value used as the base. |
| `exponent` | `number` | The power to which the base is raised. |

**Returns:** `number`
