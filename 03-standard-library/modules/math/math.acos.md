# `math.acos`

```lua
math.acos(val: number) -> number
```

Computes the inverse cosine of val, yielding the angle in radians whose cosine equals val, provided val is within [-1.0, 1.0]; otherwise returns NaN.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Input cosine value must be between -1.0 and 1.0 inclusive. |

**Returns:** `number`
