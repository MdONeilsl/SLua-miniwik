# `bit32.smul`

```lua
bit32.smul(val1: number, val2: number) -> number
```

Computes the 32-bit signed integer product of two inputs, with overflow wrapping and no floating-point precision loss, matching LSL’s integer multiplication semantics.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val1` | `number` | First operand in the multiplication. |
| `val2` | `number` | Second operand in the multiplication. |

**Returns:** `number`
