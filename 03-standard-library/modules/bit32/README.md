# bit32

This folder contains various functions for performing low-level 32-bit bitwise arithmetic and manipulation in SLua.

| Path | Contents |
|---|---|
| [arshift](bit32.arshift.md) | Arithmetic right shift propagating sign bit |
| [band](bit32.band.md) | Bitwise logical AND of two values |
| [bnot](bit32.bnot.md) | One's complement or bitwise negation |
| [bor](bit32.bor.md) | Bitwise logical OR of two values |
| [btest](bit32.btest.md) | Checks if bitwise AND result is non-zero |
| [bxor](bit32.bxor.md) | Bitwise logical XOR of two values |
| [byteswap](bit32.byteswap.md) | Swaps byte order in a 32-bit value |
| [countlz](bit32.countlz.md) | Counts number of leading zero bits |
| [countrz](bit32.countrz.md) | Counts number of trailing zero bits |
| [extract](bit32.extract.md) | Extracts specified bit range from source |
| [lrotate](bit32.lrotate.md) | Rotates value bits to the left |
| [lshift](bit32.lshift.md) | Shifts value bits to the left |
| [replace](bit32.replace.md) | Replaces specified bit range in destination |
| [rrotate](bit32.rrotate.md) | Rotates value bits to the right |
| [rshift](bit32.rshift.md) | Shifts value bits to the right |
| [s32](bit32.s32.md) | Converts number to signed 32-bit value |
| [smul](bit32.smul.md) | Multiplies two numbers using signed 32-bit math |
