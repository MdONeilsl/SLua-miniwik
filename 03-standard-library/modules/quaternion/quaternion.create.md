# `quaternion.create`

```lua
quaternion.create(x: number, y: number, z: number, s: number) -> quaternion
```

This function constructs an instance of a quaternion using four specified numerical components (x, y, z, and s). It initializes the object with these provided values.

## Arguments

| Name | Type | Description |
|---|---|---|
| `x` | `number` | Component representing the X dimension. |
| `y` | `number` | Component representing the Y dimension. |
| `z` | `number` | Component representing the Z dimension. |
| `s` | `number` | The scalar magnitude of the resulting quaternion. |

**Returns:** `quaternion`
