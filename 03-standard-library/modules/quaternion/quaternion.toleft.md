# `quaternion.toleft`

```lua
quaternion.toleft(q: quaternion) -> vector
```

The function computes the direction vector aligned with the positive Y axis after applying the rotation defined by quaternion `q`.

## Arguments

| Name | Type | Description |
|---|---|---|
| `q` | `quaternion` | Rotation to apply to the Y-axis unit vector. |

**Returns:** `vector`
