# `quaternion.dot`

```lua
quaternion.dot(q1: quaternion, q2: quaternion) -> number
```

Computes the scalar product of two quaternions, yielding a real number proportional to their alignment.

## Arguments

| Name | Type | Description |
|---|---|---|
| `q1` | `quaternion` | First quaternion operand for the dot product. |
| `q2` | `quaternion` | Second quaternion operand for the dot product. |

**Returns:** `number`
