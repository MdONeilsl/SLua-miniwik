# `quaternion.toup`

```lua
quaternion.toup(q: quaternion) -> vector
```

The function transforms a rotation quaternion into a unit vector aligned with the positive Z axis in the rotated coordinate system.

## Arguments

| Name | Type | Description |
|---|---|---|
| `q` | `quaternion` | Rotation quaternion to apply to the up vector. |

**Returns:** `vector`
