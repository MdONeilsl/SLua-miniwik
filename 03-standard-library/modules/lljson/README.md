# lljson

This folder provides utilities for encoding and decoding Lua values to standard JSON format.

| Path | Contents |
|---|---|
| [array_mt](lljson.array_mt.md) | Metatable declaring table as array |
| [decode](lljson.decode.md) | Decodes JSON string into Lua value |
| [empty_array](lljson.empty_array.md) | Constant for empty array encoding |
| [empty_object](lljson.empty_object.md) | Constant for empty object encoding |
| [encode](lljson.encode.md) | Encodes Lua value into JSON string |
| [null](lljson.null.md) | Constant representing null value |
| [object_mt](lljson.object_mt.md) | Metatable declaring table as object |
| [remove](lljson.remove.md) | Omit item using reviver/replacer function |
| [sldecode](lljson.sldecode.md) | Decodes JSON preserving SL types |
| [slencode](lljson.slencode.md) | Encodes Lua value preserving SL types |
