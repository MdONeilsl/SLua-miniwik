# `integer.ge`

```lua
integer.ge(int1: integer, int2: integer) -> boolean
```

Determines if the first integer value is numerically greater than or equal to the second one. The comparison respects standard signed integer rules.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The initial integer value used for comparison. |
| `int2` | `integer` | The second integer value against which the first is checked. |

**Returns:** `boolean`
