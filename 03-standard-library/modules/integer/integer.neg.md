# `integer.neg`

```lua
integer.neg(val: integer) -> integer
```

Calculates the additive inverse of the input value. If attempting to negate the minimum signed integer, the result will equal the original minimum due to arithmetic overflow.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `integer` | The integer value that needs its negative counterpart calculated. |

**Returns:** `integer`
