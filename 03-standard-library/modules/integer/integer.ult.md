# `integer.ult`

```lua
integer.ult(int1: integer, int2: integer) -> boolean
```

Determines if the first given integer is strictly smaller than the second when both values are treated as unsigned numbers.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The initial value used for comparison. |
| `int2` | `integer` | The subsequent value against which the first is compared. |

**Returns:** `boolean`
