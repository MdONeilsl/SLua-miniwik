# `integer.ugt`

```lua
integer.ugt(int1: integer, int2: integer) -> boolean
```

Checks whether the first integer exceeds the second when evaluated under an unsigned context.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The primary integer participating in the check. |
| `int2` | `integer` | The second integer involved in the comparison. |

**Returns:** `boolean`
