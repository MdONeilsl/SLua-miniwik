# `integer.max`

```lua
integer.max(val: integer, ...) -> integer
```

Determines the largest magnitude among a set of provided signed integers.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `integer` | The primary integer used in determining the maximum value. |
| `...` | `...integer` | Additional integers contributing to the calculation of the maximum. |

**Returns:** `integer`
