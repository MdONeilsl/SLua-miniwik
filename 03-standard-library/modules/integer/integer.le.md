# `integer.le`

```lua
integer.le(int1: integer, int2: integer) -> boolean
```

Returns true if the first integer is less than or equal to the second, using signed comparison.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The value being compared on the left. |
| `int2` | `integer` | The value being compared on the right. |

**Returns:** `boolean`
