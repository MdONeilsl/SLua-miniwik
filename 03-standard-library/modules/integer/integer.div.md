# `integer.div`

```lua
integer.div(dividend: integer, divisor: integer) -> integer
```

Computes the signed quotient of dividend divided by divisor, rounding the result toward zero. If the second argument is zero, this function will raise an error.

## Arguments

| Name | Type | Description |
|---|---|---|
| `dividend` | `integer` | The integer value that serves as the numerator. |
| `divisor` | `integer` | The integer number used for division. |

**Returns:** `integer`
