# `integer.mul`

```lua
integer.mul(int1: integer, int2: integer) -> integer
```

Calculates the multiplication result for two 64-bit integers, supporting both signed and unsigned values while handling overflow via wrapping.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The initial integer operand used in the calculation. |
| `int2` | `integer` | The second integer factor for multiplication. |

**Returns:** `integer`
