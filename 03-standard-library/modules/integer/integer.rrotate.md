# `integer.rrotate`

```lua
integer.rrotate(val: integer, i: integer) -> integer
```

Computes a rotation of the value by `i` bit positions toward the right. If the provided shift amount is negative, the function executes a left rotation instead.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `integer` | The integer value that will undergo rotation. |
| `i` | `integer` | Specifies how many bit positions are shifted. |

**Returns:** `integer`
