# `integer.gt`

```lua
integer.gt(int1: integer, int2: integer) -> boolean
```

This function evaluates whether the value stored in `int1` exceeds the value stored in `int2`. It returns a boolean result indicating if this signed inequality is true.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The first integer used for comparison. |
| `int2` | `integer` | The second integer against which the first is compared. |

**Returns:** `boolean`
