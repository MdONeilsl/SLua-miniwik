# `integer.urem`

```lua
integer.urem(dividend: integer, divisor: integer) -> integer
```

Computes the unsigned remainder when dividing the dividend by the divisor, ignoring sign; throws an error if the divisor is zero.

## Arguments

| Name | Type | Description |
|---|---|---|
| `dividend` | `integer` | The number to be divided. |
| `divisor` | `integer` | The number by which to divide, must not be zero. |

**Returns:** `integer`
