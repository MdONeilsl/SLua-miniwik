# `integer.lt`

```lua
integer.lt(int1: integer, int2: integer) -> boolean
```

Determines if the first signed integer is strictly smaller than the second one.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The initial integer value for comparison. |
| `int2` | `integer` | The final integer used as a reference point. |

**Returns:** `boolean`
