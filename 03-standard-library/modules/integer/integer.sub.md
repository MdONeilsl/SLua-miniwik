# `integer.sub`

```lua
integer.sub(int1: integer, int2: integer) -> integer
```

Computes the 64-bit signed or unsigned difference between two integers, with wraparound behavior on overflow.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | Value from which to subtract the second integer. |
| `int2` | `integer` | Value to subtract from the first integer. |

**Returns:** `integer`
