# `integer.tonumber`

```lua
integer.tonumber(val: integer) -> number
```

Converts an integer value into a floating-point representation (float64). Be aware that accuracy diminishes when the input magnitude surpasses $2^{53}$.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `integer` | The integer value intended for number conversion. |

**Returns:** `number`
