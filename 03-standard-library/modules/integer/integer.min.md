# `integer.min`

```lua
integer.min(val: integer, ...) -> integer
```

Calculates and returns the lowest numerical value present among all provided signed integers.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `integer` | One integer included in the calculation for the smallest value. |
| `...` | `...integer` | Any additional numbers that contribute to finding the minimum. |

**Returns:** `integer`
