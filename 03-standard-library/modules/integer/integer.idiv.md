# `integer.idiv`

```lua
integer.idiv(dividend: integer, divisor: integer) -> integer
```

Computes the quotient of dividend divided by divisor using signed arithmetic. The result is rounded toward negative infinity, and an error occurs if the second argument equals zero.

## Arguments

| Name | Type | Description |
|---|---|---|
| `dividend` | `integer` | The integer value to be divided. |
| `divisor` | `integer` | The integer number used as the divisor. |

**Returns:** `integer`
