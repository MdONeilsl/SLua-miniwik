# `integer.uge`

```lua
integer.uge(int1: integer, int2: integer) -> boolean
```

Returns true if the first integer is greater than or equal to the second, treating both values as unsigned.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | First operand for unsigned comparison. |
| `int2` | `integer` | Second operand for unsigned comparison. |

**Returns:** `boolean`
