# `integer.add`

```lua
integer.add(int1: integer, int2: integer) -> integer
```

Calculates the total when combining two 64-bit integers. This operation supports both signed and unsigned values, ensuring that overflow results in wrapping behavior.

## Arguments

| Name | Type | Description |
|---|---|---|
| `int1` | `integer` | The first operand for addition. |
| `int2` | `integer` | The second number to be added to the first. |

**Returns:** `integer`
