# coroutine

This folder details functions for managing and controlling coroutines.

| Path | Contents |
|---|---|
| [close](coroutine.close.md) | Safely closes a running coroutine instance |
| [create](coroutine.create.md) | Creates a new runnable coroutine object |
| [isyieldable](coroutine.isyieldable.md) | Checks if current coroutine can yield |
| [resume](coroutine.resume.md) | Continues execution of suspended coroutine |
| [running](coroutine.running.md) | Gets the active executing coroutine context |
| [status](coroutine.status.md) | Retrieves current coroutine operational status |
| [wrap](coroutine.wrap.md) | Wraps routine into resumable function |
| [yield](coroutine.yield.md) | Pauses execution yielding control flow |
