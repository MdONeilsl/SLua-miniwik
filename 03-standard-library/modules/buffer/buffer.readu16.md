# `buffer.readu16`

```lua
buffer.readu16(b: buffer, offset: number) -> number
```

Reads and returns an unsigned integer composed of 16 bits found within the specified data block at a given location.

## Arguments

| Name | Type | Description |
|---|---|---|
| `b` | `buffer` | The memory container from which to retrieve data. |
| `offset` | `number` | Starting position, measured in bytes, for reading the value. |

**Returns:** `number`
