# `buffer.readu8`

```lua
buffer.readu8(b: buffer, offset: number) -> number
```

This function extracts an unsigned integer consisting of 8 bits stored within the provided memory buffer, starting at the specified index.

## Arguments

| Name | Type | Description |
|---|---|---|
| `b` | `buffer` | The memory buffer containing the data for reading. |
| `offset` | `number` | The starting position, measured in bytes, for the data retrieval. |

**Returns:** `number`
