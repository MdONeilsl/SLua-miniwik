# `buffer.readi32`

```lua
buffer.readi32(b: buffer, offset: number) -> number
```

This method retrieves an integer of 32 bits, which is signed, using the provided starting position within the buffer.

## Arguments

| Name | Type | Description |
|---|---|---|
| `b` | `buffer` | The data buffer used for reading the value. |
| `offset` | `number` | The starting position, measured in bytes, for the reading operation. |

**Returns:** `number`
