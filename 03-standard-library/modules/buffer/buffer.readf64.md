# `buffer.readf64`

```lua
buffer.readf64(b: buffer, offset: number) -> number
```

Retrieves a double-precision floating-point value stored within the provided data container, starting at the specified byte position.

## Arguments

| Name | Type | Description |
|---|---|---|
| `b` | `buffer` | The source data structure used for reading values. |
| `offset` | `number` | The initial byte index where reading must begin. |

**Returns:** `number`
