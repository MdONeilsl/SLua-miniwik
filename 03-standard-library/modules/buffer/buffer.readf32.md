# `buffer.readf32`

```lua
buffer.readf32(b: buffer, offset: number) -> number
```

Retrieves a single-precision floating-point value from the specified location within the buffer data structure.

## Arguments

| Name | Type | Description |
|---|---|---|
| `b` | `buffer` | The source container of binary data to read. |
| `offset` | `number` | Starting index in bytes, zero indexed. |

**Returns:** `number`
