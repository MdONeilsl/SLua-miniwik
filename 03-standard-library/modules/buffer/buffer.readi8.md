# `buffer.readi8`

```lua
buffer.readi8(b: buffer, offset: number) -> number
```

Extracts a signed integer represented by 8 bits from the memory block at the provided position.

## Arguments

| Name | Type | Description |
|---|---|---|
| `b` | `buffer` | The data container used for reading values. |
| `offset` | `number` | Zero-indexed byte location where reading begins. |

**Returns:** `number`
