# `os.time`

```lua
os.time(time: DateTypeArg) -> number?
```

Computes the Unix timestamp for the current moment, or converts a specified date object into its corresponding time value.

## Arguments

| Name | Type | Description |
|---|---|---|
| `time` | `DateTypeArg?` | Optional table containing date and time components for conversion. |

**Returns:** `number?`
