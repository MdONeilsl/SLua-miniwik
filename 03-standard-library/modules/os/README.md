# os

The `os` module provides functions for retrieving and manipulating system time, dates, and durations within SLua scripts.

| Path | Contents |
|---|---|
| [clock](os.clock.md) | High-precision timestamp for duration measurement |
| [date](os.date.md) | Format-based date and time representation |
| [difftime](os.difftime.md) | Calculates difference between two timestamps |
| [time](os.time.md) | Retrieves current or specific Unix time |
