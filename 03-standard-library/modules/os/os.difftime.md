# `os.difftime`

```lua
os.difftime(a: number, b: number) -> number
```

Calculates the temporal difference between two time points, yielding the result in seconds. This operation is mathematically equivalent to subtracting the second value from the first.

## Arguments

| Name | Type | Description |
|---|---|---|
| `a` | `number` | The initial timestamp value supplied. |
| `b` | `number` | The subsequent timestamp value supplied. |

**Returns:** `number`
