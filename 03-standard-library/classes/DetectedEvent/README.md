# DetectedEvent

This folder details properties and methods available when an entity is detected by another object or avatar.

| Path | Contents |
|---|---|
| [adjustDamage](DetectedEvent.adjustDamage.md) | Adjusting damage applied to detected entities |
| [canAdjustDamage](DetectedEvent.canAdjustDamage.md) | Checks if damage adjustment is possible |
| [getGrab](DetectedEvent.getGrab.md) | Retrieves the attached grab link information |
| [getGroup](DetectedEvent.getGroup.md) | Gets the group ID of detected object |
| [getKey](DetectedEvent.getKey.md) | Returns the unique key identifier |
| [getLinkNumber](DetectedEvent.getLinkNumber.md) | The link number |
| [getName](DetectedEvent.getName.md) | Retrieves the name of detected object |
| [getOwner](DetectedEvent.getOwner.md) | Gets the owner UUID |
| [getPos](DetectedEvent.getPos.md) | Position vector of the detected entity |
| [getRezzer](DetectedEvent.getRezzer.md) | The rezzer's uuid of the detected entity |
| [getRot](DetectedEvent.getRot.md) | Rotation quaternion of the detected object |
| [getTouchBinormal](DetectedEvent.getTouchBinormal.md) | Binormal vector at touch point |
| [getTouchFace](DetectedEvent.getTouchFace.md) | The face that was touched |
| [getTouchNormal](DetectedEvent.getTouchNormal.md) | Normal vector at touch location |
| [getTouchPos](DetectedEvent.getTouchPos.md) | Position vector of the touch point |
| [getTouchST](DetectedEvent.getTouchST.md) | ST coordinates at touch location |
| [getTouchUV](DetectedEvent.getTouchUV.md) | UV coordinates at touch location |
| [getType](DetectedEvent.getType.md) | Determines the type of detected entity |
| [getVel](DetectedEvent.getVel.md) | Velocity vector of the detected object |
| [index](DetectedEvent.index.md) | Index number of the detected entity |
| [valid](DetectedEvent.valid.md) | Checks if detection data is valid |
