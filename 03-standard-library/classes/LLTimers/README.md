# LLTimers

This folder provides functions for scheduling recurring or single-shot events within the SLua environment.

| Path | Contents |
|---|---|
| [every](LLTimers.every.md) | Repeating interval timer registration function |
| [off](LLTimers.off.md) | Stops and removes active timers |
| [once](LLTimers.once.md) | Registers a single-run timer event |
