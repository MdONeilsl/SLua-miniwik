# LLEvents

This folder provides functions for registering, managing events.

| Path | Contents |
|---|---|
| [eventNames](LLEvents.eventNames.md) | List of active registered event names |
| [handlers](LLEvents.handlers.md) | All functions handling a specific event |
| [off](LLEvents.off.md) | Removes a previously registered event handler |
| [on](LLEvents.on.md) | Registering functions for specific events |
| [once](LLEvents.once.md) | One-time execution event registration |
