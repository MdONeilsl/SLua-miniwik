Stand-alone offline reference for **SLua**, the scripting language of the Second Life® main grid. Everything a scripter needs, in one downloadable folder.

Every page is generated from live in-world test runs against the current main-grid version. What the simulator actually accepts is what this document states.

## How to use it

1. **Get a Markdown explorer.** Any Markdown viewer works. QMarkdown-explorer was made especially for this purpose. https://github.com/MdONeilsl/QMarkdown-explorer
2. **Download this repository** and extract it anywhere on your computer.
3. **Open the root folder** in your Markdown explorer of choice. The miniwik now works locally, offline, with no network access required.

| Chapter | Contains |
|---|---|
| 01-getting-started | Syntax, types, control flow, functions, scripts — read this first |
| 02-environment | Object lifecycle, memory, coordinates, serialization, permissions |
| 03-standard-library | table, string, math, vector, quaternion, uuid, buffer, integer, json, and more |
| 04-ll-library | Every `ll.*` function, event, and constant |
| 05-strategy | Singleton, object factory, unit testing |
