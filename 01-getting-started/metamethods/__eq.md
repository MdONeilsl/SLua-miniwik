# `__eq`

```lua
__eq(left: {}, right: {}) -> boolean
```

When the == comparison operator is used and one of the operands is a table containing this metamethod, it dictates how value equality is determined.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `{}` | The initial object utilized in the comparison check. |
| `right` | `{}` | The second object participating in the equality test. |

**Returns:** `boolean`
