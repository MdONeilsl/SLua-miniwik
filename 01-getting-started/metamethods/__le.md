# `__le`

```lua
__le(left: {}, right: {}) -> boolean
```

When the <= comparison operator is invoked and either of the operands possesses this method, it determines the boolean result of the check.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `{}` | The value used on the left side during comparison. |
| `right` | `{}` | The value used on the right side during comparison. |

**Returns:** `boolean`
