# `__mul`

```lua
__mul(left: any, right: any) -> any
```

When the * operator is applied and one or both operands are tables defining this metamethod, the function determines the result of the multiplication operation.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The object on the left side of the * operator. |
| `right` | `any` | The object placed to the right of the * operator. |

**Returns:** `any`
