# `__unm`

```lua
__unm(self: {}) -> any
```

When the unary minus operator is applied, and the operand is a table containing this metamethod, the defined behavior dictates the result of the negation.

## Arguments

| Name | Type | Description |
|---|---|---|
| `self` | `{}` | The object or value that is subject to negation. |

**Returns:** `any`
