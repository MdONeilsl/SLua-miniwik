# `__idiv`

```lua
__idiv(left: any, right: any) -> any
```

When the // operator is applied and one of the operands is a table containing this metamethod, it defines how the floor division should be calculated.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The value on the left side of the // operation. |
| `right` | `any` | The value on the right side of the // operation. |

**Returns:** `any`
