# `__pow`

```lua
__pow(left: any, right: any) -> any
```

When the ^ operator is applied to an object containing this metamethod, it dictates how the base value should be raised to the power of the exponent.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The base number for the exponentiation operation. |
| `right` | `any` | The power to which the base is raised. |

**Returns:** `any`
