# `__lt`

```lua
__lt(left: {}, right: {}) -> boolean
```

When the less-than comparison operator (<) is used and one of the operands is a table containing this metamethod, it determines how the comparison should be performed.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `{}` | The object on the left side of the less-than operator. |
| `right` | `{}` | The object on the right side of the less-than operator. |

**Returns:** `boolean`
