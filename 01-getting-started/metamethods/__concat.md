# `__concat`

```lua
__concat(left: any, right: any) -> any
```

When this metamethod is invoked via the `..` operator, it determines how two values are combined into a single result.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The initial value or item that will be joined. |
| `right` | `any` | The subsequent value or item intended for joining. |

**Returns:** `any`
