# `__sub`

```lua
__sub(left: any, right: any) -> any
```

When the binary subtraction (-) operation is performed and one of the operands possesses this metamethod, its return value dictates the outcome.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The initial value used for the subtraction calculation. |
| `right` | `any` | The second value that is taken away from the first. |

**Returns:** `any`
