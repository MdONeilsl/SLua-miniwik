# `__div`

```lua
__div(left: any, right: any) -> any
```

When the / operator is invoked and one of the operands is a table containing this metamethod, it determines how the division calculation should be performed.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The value on the left side, acting as the dividend for the operation. |
| `right` | `any` | The value on the right side, which serves as the divisor. |

**Returns:** `any`
