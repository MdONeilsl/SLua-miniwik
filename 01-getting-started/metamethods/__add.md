# `__add`

```lua
__add(left: any, right: any) -> any
```

When the addition operator (`+`) is used and one of the operands is a table containing this metamethod, it determines how the arithmetic operation should be executed.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The value positioned on the left side when using the addition operator. |
| `right` | `any` | The value positioned on the right side when using the addition operator. |

**Returns:** `any`
