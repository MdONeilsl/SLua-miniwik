# `__mod`

```lua
__mod(left: any, right: any) -> any
```

When the % operator is used and one of the operands is a table containing this metamethod, it determines the result of the modulus calculation.

## Arguments

| Name | Type | Description |
|---|---|---|
| `left` | `any` | The first value used in the calculation (the dividend). |
| `right` | `any` | The second value used in the calculation (the divisor). |

**Returns:** `any`
