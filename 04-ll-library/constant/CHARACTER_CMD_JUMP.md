# `CHARACTER_CMD_JUMP`

This command initiates a jump for the character, which necessitates specifying a height value ranging from 0.1m up to 2.0m; this height must be provided as the initial item in the `ll.ExecCharacterCmd` option list.

**Type:** `number`

**Value:** `0x01`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `CharacterCommand` |
