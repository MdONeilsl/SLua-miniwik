# `TERRAIN_PBR_ROTATION_4`

This terrain parameter is utilized with ll.SetGroundTexture when you need to specify the rotational angle, measured in radians, for the PBR texture associated with layer 4. This functionality is restricted exclusively to PBR textures.

**Type:** `number`

**Value:** `15`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
