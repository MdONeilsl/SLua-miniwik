# `PRIM_GLTF_ALPHA_MODE_OPAQUE`

This constant specifies the GLTF alpha mode for PRIM_GLTF_BASE_COLOR, ensuring that the rendering process disregards the alpha channel and displays the face material with full opacity.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFAlphaMode` |
