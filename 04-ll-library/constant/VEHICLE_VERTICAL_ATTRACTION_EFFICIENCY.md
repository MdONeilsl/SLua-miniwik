# `VEHICLE_VERTICAL_ATTRACTION_EFFICIENCY`

This floating-point parameter for vehicles, which accepts values between 0.0 and 1.0, manages how stable the vertical attraction force is used to maintain the vehicle's upright position (a value of 0.0 indicates a wobbly or bouncy state, while 1.0 represents critically damped/firm stability).

**Type:** `number`

**Value:** `36`
