# `REZ_VEL`

This Rez argument determines the starting speed to be assigned to the object. It accepts a list containing either a vector representing the velocity, or two integers for local and inherit settings. When `inherit` is set to TRUE, the object will incorporate the rezzing object's existing velocity.

**Type:** `number`

**Value:** `4`
