# `CHANGED_OWNER`

This trigger fires because the object's ownership status has been modified. It executes in the initial object whenever a user acquires, duplicates, or assigns ownership to a group, and subsequently runs in the newly created instance upon its initial appearance.

**Type:** `number`

**Value:** `0x80`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ChangeType` |
