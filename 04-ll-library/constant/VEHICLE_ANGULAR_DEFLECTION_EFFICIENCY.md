# `VEHICLE_ANGULAR_DEFLECTION_EFFICIENCY`

This float parameter for the Vehicle controls an angular deflection magnitude using a scalar input (which spans from 0.0 to 1.0), thereby adjusting how strongly the vehicle's inherent orientation is corrected towards matching its actual speed vector.

**Type:** `number`

**Value:** `32`
