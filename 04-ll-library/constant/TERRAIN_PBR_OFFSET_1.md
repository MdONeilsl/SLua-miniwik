# `TERRAIN_PBR_OFFSET_1`

This parameter, utilized by ll.SetGroundTexture, defines the UV offset vector's X and Y components when rendering the first terrain layer. It is restricted to use with PBR textures exclusively.

**Type:** `number`

**Value:** `16`

| Field | Value |
|---|---|
