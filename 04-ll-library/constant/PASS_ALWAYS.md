# `PASS_ALWAYS`

When utilizing functions designed for passing events (such as ll.PassTouches or ll.PassCollisions), this value guarantees that all events travel from a contained child prim up to the main root prim, even if intermediate child scripts have already processed them.

**Type:** `number`

**Value:** `1`

|---|---|
