# `PSYS_PART_START_SCALE`

This vector parameter, represented as `<sx, sy, z>`, specifies the initial dimensions of the particle billboard using meters for measurement; note that the value assigned to the z-axis has no effect.

**Type:** `number`

**Value:** `5`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParticleParam` |
