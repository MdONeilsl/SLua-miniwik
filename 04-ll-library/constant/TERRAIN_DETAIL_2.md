# `TERRAIN_DETAIL_2`

This integer parameter is utilized alongside `ll.SetGroundTexture` to define the texture or material—which can be specified using a UUID, an item's inventory name, or by leaving it as the default NULL_KEY/empty string—for the second detail layer of the terrain.

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
