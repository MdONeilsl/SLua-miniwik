# `AGENT_FLOATING_VIA_SCRIPTED_ATTACHMENT`

When utilizing ll.GetAgentInfo, this constant helps ascertain whether an avatar's position indicates floating or hovering status resulting from a programmatic attachment implemented via either ll.SetHoverHeight or ll.GroundRepel.

**Type:** `number`

**Value:** `0x8000`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `AgentInfo` |
