# `PARCEL_COUNT_OTHER`

When utilizing `ll.GetParcelPrimCount`, this constant retrieves the land usage count for every object that does not belong to the parcel owner and is also not associated with, or owned by, the parcel's designated group.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelPrimCountCategory` |
