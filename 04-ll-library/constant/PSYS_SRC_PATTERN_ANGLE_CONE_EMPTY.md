# `PSYS_SRC_PATTERN_ANGLE_CONE_EMPTY`

This incomplete emission pattern mimics the behavior of the DROP pattern. It is designed for inverting the ANGLE parameters, thereby defining a zone that contains no emitted particles.

**Type:** `number`

**Value:** `0x10`
