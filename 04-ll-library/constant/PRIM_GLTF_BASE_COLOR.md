# `PRIM_GLTF_BASE_COLOR`

This parameter allows retrieving or setting the GLTF base color override for an object's face. It necessitates providing values for face, texture, repeats, offsets, rotation, linear_color (which must be in linear space; use llsRGB2Linear), alpha_mode (PRIM_GLTF_ALPHA_MODE_*), alpha_cutoff, and double_sided.

**Type:** `number`

**Value:** `48`
