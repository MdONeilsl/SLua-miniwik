# `PARCEL_DETAILS_LANDING_LOOKAT`

When utilizing ll.GetParcelDetails, this flag enables the retrieval of a specific lookat vector associated with the landing spot (used for teleport routing) on the current parcel, provided such a vector exists.

**Type:** `number`

**Value:** `10`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelDetailsParam` |
