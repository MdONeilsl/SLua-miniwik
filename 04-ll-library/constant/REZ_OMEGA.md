# `REZ_OMEGA`

This Rez parameter sets the starting angular velocity (omega) for an object. It supports several types of input: a vector specifying the axis, an integer indicating relativity, and floating-point values for spin and gain. Note that if relative is set to TRUE, the provided axis vector will be interpreted using local coordinates.

**Type:** `number`

**Value:** `7`
