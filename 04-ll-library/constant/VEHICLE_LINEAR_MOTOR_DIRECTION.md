# `VEHICLE_LINEAR_MOTOR_DIRECTION`

This is a vehicle vector parameter used to define both the directional heading and the scale of the linear speed (which must be between 0 and 30 m/s) that the vehicle's dedicated linear motor will aim for.

**Type:** `number`

**Value:** `18`
