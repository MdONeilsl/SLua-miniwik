# `KFM_REVERSE`

When employed as a playback setting with KFM_MODE within ll.SetKeyframedMotion, this constant causes the motion sequence to play backward, traversing from frame N down to frame 1 before ceasing execution.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionMode` |
