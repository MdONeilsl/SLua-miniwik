# `TERRAIN_DETAIL_4`

This terrain parameter is utilized with ll.SetGroundTexture to specify the desired texture or material for the fourth level of terrain detail, which can be provided using a UUID, an inventory name, or by default setting it to NULL_KEY/empty string.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
