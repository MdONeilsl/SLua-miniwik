# `KFM_CMD_PAUSE`

When utilizing KFM_COMMAND within the ll.SetKeyframedMotion function, this command instructs the system to temporarily suspend the ongoing keyframed movement without reverting the animation's state to its initial position.

**Type:** `number`

**Value:** `2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionCommand` |
