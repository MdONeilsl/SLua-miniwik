# `CHARACTER_LENGTH`

This parameter determines the longitudinal length of the collision capsule used by a pathfinding entity. Should the assigned value fall below the calculated minimum (twice the radius plus 0.1m), the system will automatically adjust it to match that minimum.

**Type:** `number`

**Value:** `3`
