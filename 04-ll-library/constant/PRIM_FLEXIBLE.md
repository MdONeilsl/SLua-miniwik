# `PRIM_FLEXIBLE`

A prim property used to retrieve or modify the flexible physical settings associated with a prim.
integer boolean – TRUE activates the setting, and FALSE deactivates it
integer softness – must be between 0 and 3
float gravity – accepts values from -10.0 through 10.0
float friction – accepts values from 0.0 through 10.0
float wind – accepts values from 0.0 through 10.0
float tension – accepts values from 0.0 through 10.0
vector force

**Type:** `number`

**Value:** `21`
