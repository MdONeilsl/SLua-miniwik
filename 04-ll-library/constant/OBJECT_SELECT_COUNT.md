# `OBJECT_SELECT_COUNT`

This flag, utilized alongside ll.GetObjectDetails, retrieves a count representing all agents or avatars that are currently selecting any connection within the specified object; note that it will return 0 if the designated target is itself an avatar.

**Type:** `number`

**Value:** `37`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
