# `TERRAIN_PBR_ROTATION_1`

This terrain parameter is utilized with `ll.SetGroundTexture` to define the angular rotation of the PBR texture designated for layer 1, which must be specified in radians. Please note that this feature is functional solely when dealing with PBR textures.

**Type:** number

**Value:** `12`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
