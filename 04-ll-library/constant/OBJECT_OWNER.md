# `OBJECT_OWNER`

When utilizing ll.GetObjectDetails, this flag enables retrieval of the object's owning key. Should the item belong to a specific user avatar, that user's unique key will be provided; otherwise, if it is owned by a group, NULL_KEY is returned.

**Type:** `number`

**Value:** `6`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
