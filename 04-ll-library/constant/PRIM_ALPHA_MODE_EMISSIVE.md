# `PRIM_ALPHA_MODE_EMISSIVE`

This setting modifies the `PRIM_ALPHA_MODE` parameter for Prim. It utilizes the diffuse texture's alpha channel to create an emissivity mask, ensuring that pixel emissivity matches its opacity across every lighting scenario; specifically, fully opaque pixels will appear as 'full bright'.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `AlphaMode` |
