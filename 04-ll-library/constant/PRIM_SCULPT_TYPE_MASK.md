# `PRIM_SCULPT_TYPE_MASK`

This bitmask assists in dissecting sculpted primitive parameters (PRIM_TYPE_SCULPT) obtained via ll.GetPrimitiveParams, allowing separation of the core sculpt type definition from any associated modification flags like mirroring or inversion.

**Type:** `number`

**Value:** `7`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimTypeSculptType` |
