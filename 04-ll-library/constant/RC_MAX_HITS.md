# `RC_MAX_HITS`

When utilizing ll.CastRay, this flag determines the upper limit for the count of returned intersections (this limit cannot exceed 256). For optimal performance, it is recommended that you maintain a low value for this setting.

**Type:** `number`

**Value:** `3`
