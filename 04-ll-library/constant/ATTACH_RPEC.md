# `ATTACH_RPEC`

This constant identifies an attachment location situated on the avatar's left pectoral area; note that this value is deprecated and developers should instead utilize `ATTACH_LEFT_PEC`.

**Type:** `number`

**Value:** `29`

## Deprecated

- **use:** ATTACH_LEFT_PEC
