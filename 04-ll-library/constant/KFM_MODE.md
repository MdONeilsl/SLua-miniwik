# `KFM_MODE`

This option flag is utilized within ll.SetKeyframedMotion and accepts KFM_LOOP, KFM_REVERSE, KFM_FORWARD, or KFM_PING_PONG to establish the playback mode; it defaults to KFM_FORWARD if not set. It is mandatory that this parameter be defined when providing a keyframe list.

**Type:** `number`

**Value:** `1`

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionParam` |
