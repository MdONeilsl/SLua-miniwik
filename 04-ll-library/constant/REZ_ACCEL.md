# `REZ_ACCEL`

This `Rez` parameter defines a fixed acceleration that will act upon the object being rezzed, requiring a pairing of a vector representing the force and an integer indicating relativity. Note that if the value for `relative` is set to TRUE, the associated vector components must be expressed using local coordinates.

**Type:** `number`

**Value:** `5`
