# `OBJECT_PRIM_COUNT`

When utilizing ll.GetObjectDetails, this flag retrieves the total number of individual prims belonging to the specified object. It is important to remember that both the executing script and the intended target object need to share the same ownership account.

**Type:** `number`

**Value:** `30`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
