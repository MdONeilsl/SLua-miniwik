# `PU_FAILURE_PARCEL_UNREACHABLE`

This error code signals that a path update failed because the character could not enter a specific area or "parcel." This might occur if the designated parcel has reached capacity or if object entry restrictions were applied subsequent to the navigation mesh generation process.

**Type:** `number`

**Value:** `11`

|---|---|
