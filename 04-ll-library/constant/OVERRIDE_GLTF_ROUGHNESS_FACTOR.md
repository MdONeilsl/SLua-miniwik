# `OVERRIDE_GLTF_ROUGHNESS_FACTOR`

This GLTF override parameter, which works alongside ll.SetLinkGLTFOverrides, allows adjustment of the roughness value for designated faces, restricting the input to a range from 0 through 1.

**Type:** `number`

**Value:** `7`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFOverride` |
