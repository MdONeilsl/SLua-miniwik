# `AGENT_BY_LEGACY_NAME`

This value is utilized to identify agents based on their legacy name. It serves to indicate an avatar when used with `ll.DetectedType`. Furthermore, when employed in conjunction with `ll.Sensor` or `ll.SensorRepeat`, it facilitates searching for avatars by their legacy name.

**Type:** `number`

**Value:** `0x1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `DetectType` |
