# `OVERRIDE_GLTF_BASE_ALPHA_MASK`

This GLTF override parameter, utilized by ll.SetLinkGLTFOverrides, determines the specific alpha cutoff level applied to any faces when the system's alpha mode is configured as 'mask'.

**Type:** `number`

**Value:** `4`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFOverride` |
