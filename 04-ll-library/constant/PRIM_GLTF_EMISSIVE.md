# `PRIM_GLTF_EMISSIVE`

This parameter allows retrieval or modification of the GLTF emission override associated with a face. It requires several inputs: `face`, `texture`, `repeats`, `offsets`, `rotation`, and `emissive_tint` (which must be provided in linear space; utilize llsRGB2Linear for conversion).

**Type:** `number`

**Value:** `46`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimParam`, `PrimParamGet` |
