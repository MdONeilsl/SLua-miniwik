# `OBJECT_ROOT`

When paired with `ll.GetObjectDetails`, this flag retrieves the identifier for the root prim. If the context is an avatar, it yields the root prim ID of the linkset the avatar occupies (unless the avatar is standing alone, in which case it returns the avatar's own ID).

**Type:** `number`

**Value:** `18`
