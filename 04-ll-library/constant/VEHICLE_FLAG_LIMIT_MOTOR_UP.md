# `VEHICLE_FLAG_LIMIT_MOTOR_UP`

This vehicle flag stops ground units from moving vertically upwards. Furthermore, if it is used alongside banking mechanics, the banked strength diminishes once the vehicle leaves contact with the ground, which prevents unwanted directional changes during a jump.

**Type:** `number`

**Value:** `0x40`
