# `PSYS_SRC_OUTERANGLE`

This floating-point parameter determines the maximum angular extent (outer angle) used when generating particle patterns using ANGLE or ANGLE_CONE. Particles are distributed within the region defined by this outer angle and the corresponding inner angle.

**Type:** `number`

**Value:** `11`
