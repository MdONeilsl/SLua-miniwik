# `ACTIVE`

This value signifies entities that are either in motion, whether through a script or physically, thereby consuming server resources. When used with ll.DetectedType(), it pinpoints both agents and physical items. Similarly, when utilized with ll.Sensor() or ll.SensorRepeat(), it is employed to locate moving physical objects or scripted entities.

**Type:** `number`

**Value:** `0x2`
