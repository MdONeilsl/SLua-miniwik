# `RCERR_CAST_TIME_EXCEEDED`

This error signals that either the parcel or an associated agent has surpassed its allotted maximum duration for raycasting. Typically, waiting several frames before attempting the operation again should resolve the issue because system resources will have regenerated.

**Type:** `number`

**Value:** `-3`
