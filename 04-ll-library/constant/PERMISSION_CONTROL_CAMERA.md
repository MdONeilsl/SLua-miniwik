# `PERMISSION_CONTROL_CAMERA`

This runtime permission grants scripts the ability to manage the agent's camera. This functionality requires that the agent remains seated upon or connected to the object; furthermore, the permission will be automatically withdrawn if the agent stands up or separates from the object.

**Type:** `number`

**Value:** `0x00800`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ScriptPermission` |
