# `PARCEL_MEDIA_COMMAND_SIZE`

This command interacts with `ll.ParcelMediaCommandList` or `ll.ParcelMediaQuery`, allowing for either retrieval or modification of the pixel resolution associated with parcel media.

**Type:** `number`

**Value:** `11`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand`, `ParcelMediaQuery` |
