# `PRIM_ALLOW_UNSIT`

This parameter controls whether avatars sitting on this prim are permitted or restricted from standing up manually within a functional experience. It is disregarded if the avatar did not use `ll.SitOnLink` to occupy the space. If the restriction is engaged, seated avatars cannot independently stand up or choose another prim for seating.

**Type:** `number`

**Value:** `39`
