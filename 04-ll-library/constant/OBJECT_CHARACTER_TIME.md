# `OBJECT_CHARACTER_TIME`

Use this flag with ll.GetObjectDetails when you need to retrieve the mean CPU duration, measured in seconds, that was dedicated to movement calculations, provided the specified target entity is capable of pathfinding. If the target is not a character that uses pathfinding, the function will return 0.

**Type:** `number`

**Value:** `17`
