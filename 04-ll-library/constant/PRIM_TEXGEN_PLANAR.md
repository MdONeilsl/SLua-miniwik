# `PRIM_TEXGEN_PLANAR`

This constant is a configuration option for PRIM_TEXGEN that determines how texture repetition is calculated. Specifically, it sets the measurement unit for texture repeat units to be repeats per half-meter, differing from the standard measure used within the in-world editor (which uses repeats per meter).

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimTexgen` |
