# `REZ_PARAM_STRING`

This Rez parameter is used to provide a starting string, limited to 1024 bytes in size, which will be transmitted to the primary primitive of the object when it is created (rezzed), and can subsequently be retrieved using ll.GetStartString.

**Type:** `number`

**Value:** `13`
