# `OBJECT_ACCOUNT_LEVEL`

This flag must be passed to ll.GetObjectDetails when you wish to fetch the account level of an avatar. The returned value indicates Basic status (0), Premium (1), Plus (5), Premium Plus (10), or -1 if the specified target entity is not an avatar.

**Type:** `number`

**Value:** `41`
