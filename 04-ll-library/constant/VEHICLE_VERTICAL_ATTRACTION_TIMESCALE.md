# `VEHICLE_VERTICAL_ATTRACTION_TIMESCALE`

This floating-point parameter defines the exponential decay time, measured in seconds, that governs how the vehicle adjusts its orientation, specifically aligning its local Z-axis (the 'up' direction) to match the global or world Z-axis (vertical).

**Type:** `number`

**Value:** `37`
