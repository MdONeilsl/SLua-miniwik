# `TERRAIN_PBR_OFFSET_4`

This parameter, utilized with ll.SetGroundTexture, defines the UV offset vector's XY components when rendering terrain layer 4. It is restricted to use only with PBR textures.

**Type:** `number`

**Value:** `19`

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
