# `TERRAIN_PBR_SCALE_1`

This terrain parameter is utilized by `ll.SetGroundTexture` and defines the UV scale vector—indicating how many times the texture repeats every meter while disregarding the Z axis—for the first terrain layer. Its functionality is limited to PBR textures only.

**Type:** `number`

**Value:** `8`

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
