# `PERMISSION_SILENT_ESTATE_MANAGEMENT`

This runtime permission grants the ability for a script to handle estate access configurations using ll.ManageEstateAccess, even if it does not send notifications to the owner of the object regarding these modifications.

**Type:** `number`

**Value:** `0x04000`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ScriptPermission` |
