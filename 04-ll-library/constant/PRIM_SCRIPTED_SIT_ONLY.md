# `PRIM_SCRIPTED_SIT_ONLY`

This prim parameter controls whether a user can manually sit upon it. If set to restrict sitting, users must utilize `ll.SitOnLink` to initiate sitting, as all other manual attempts will fail. Furthermore, this limitation remains in effect even when the region is not operating under experience-enabled settings.

**Type:** `number`

**Value:** `40`
