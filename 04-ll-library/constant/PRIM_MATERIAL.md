# `PRIM_MATERIAL`

This prim parameter, designated [PRIM_MATERIAL, integer PRIM_MATERIAL_*], allows retrieving or modifying the material properties of a prim. The selected material dictates default values for the collision sound, sprite, friction coefficient, and restitution coefficient (which measures elasticity), but it does not influence the object's mass.

**Type:** `number`

**Value:** `2`
