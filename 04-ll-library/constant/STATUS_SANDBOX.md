# `STATUS_SANDBOX`

A status flag that defaults to FALSE, this setting restricts an object's physical movement. It confines the object both within its designated creation area and within a limited range (10 to 20 meters) of its original point to prevent any escape attempts.

**Type:** `number`

**Value:** `0x20`
