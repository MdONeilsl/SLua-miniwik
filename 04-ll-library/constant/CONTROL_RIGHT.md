# `CONTROL_RIGHT`

This constant is used to check if the user has activated the command that moves the avatar in a rightward direction, which can be triggered by pressing `Shift` and the right arrow key (`→`) or by pressing `Shift` and `D`.

**Type:** `number`

**Value:** `0x8`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ControlButton` |
