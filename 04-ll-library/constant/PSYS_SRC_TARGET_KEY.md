# `PSYS_SRC_TARGET_KEY`

The UUID key identifying the destination object towards which particles move when either PSYS_PART_TARGET_POS_MASK or PSYS_PART_TARGET_LINEAR_MASK has been activated.

**Type:** `number`

**Value:** `20`
