# `COMBAT_CHANNEL`

This constant designates a region-wide communication channel that is dedicated to recording combat events. Utilizing this value with ll.RegionSay ensures that the transmitted message appears in the combat log, which enables scripts subscribed to this particular channel to effectively monitor related activity.

**Type:** `number`

**Value:** `2147483646`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `Channel`, `ChannelNonPublic` |
