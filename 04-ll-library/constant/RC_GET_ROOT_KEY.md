# `RC_GET_ROOT_KEY`

This flag, when used with ll.CastRay, modifies the return value to provide the key corresponding to the hit object's top-level (root) prim, rather than the specific child prim that was struck.

**Type:** `number`

**Value:** `2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `RayCastData` |
