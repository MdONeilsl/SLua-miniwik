# `PSYS_SRC_PATTERN_ANGLE`

This emission pattern directs particles outwards into a planar region—which can be circular, semi-circular, an arc, or a ray shape—confined to 2D space (centered around the prim's local X-axis). The specific geometry is controlled by specifying both the start and end angles, along with inner and outer angle parameters.

**Type:** `number`

**Value:** `0x04`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParticleSourcePattern` |
