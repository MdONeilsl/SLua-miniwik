# `REZ_POS`

This rez parameter accepts a set of arguments—a vector position, an integer for relative placement, and an integer indicating if it should be at the root—to define the target location for rezzed objects. The positioning can utilize region coordinates or reference the rezzing object's location, with centering options available on either the object itself or the prim's root.

**Type:** `number`

**Value:** `2`
