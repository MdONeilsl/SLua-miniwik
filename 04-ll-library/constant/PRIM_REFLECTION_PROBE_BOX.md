# `PRIM_REFLECTION_PROBE_BOX`

This flag option works alongside PRIM_REFLECTION_PROBE. Setting it specifies that the reflection probe's geometry should be a cuboid volume, whereas leaving it unset causes the system to use a spherical default.

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ReflectionProbeType` |
