# `PARCEL_MEDIA_COMMAND_LOOP_SET`

This command can be utilized with `ll.ParcelMediaCommandList` or `ll.ParcelMediaQuery` to either retrieve or modify the looping variable or loop duration associated with the parcel's media, though users should note potential functionality limitations detailed in VWR-19712.

**Type:** `number`

**Value:** `13`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand`, `ParcelMediaQuery` |
