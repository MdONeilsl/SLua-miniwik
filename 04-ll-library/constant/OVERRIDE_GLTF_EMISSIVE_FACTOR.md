# `OVERRIDE_GLTF_EMISSIVE_FACTOR`

This GLTF override constant, utilized by ll.SetLinkGLTFOverrides, determines the color tint—given in linear RGB values—that applies to the emissive texture assigned to a face or multiple faces.

**Type:** `number`

**Value:** `8`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFOverride` |
