# `SCRIPTED`

Indicates an object within the world that utilizes scripting. When retrieved via `ll.DetectedType()`, this means the detected target possesses at least one operational script. Furthermore, when used as a filter in `ll.Sensor()` or `ll.SensorRepeat()`, it specifies searches for objects with active and currently executing scripts.

**Type:** `number`

**Value:** `0x8`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `DetectType` |
