# `PSYS_PART_END_SCALE`

This vector parameter, `<sx, sy, z>`, specifies the dimensions—in meters—for the termination scale of the particle billboard; note that the value provided for the z-axis component will not be utilized.

**Type:** `number`

**Value:** `6`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParticleParam` |
