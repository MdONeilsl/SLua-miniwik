# `TERRAIN_PBR_SCALE_4`

This terrain constant is utilized by `ll.SetGroundTexture` and defines the UV scale vector—which represents repeats per meter but disregards the Z axis—for the fourth terrain layer. Its functionality is restricted exclusively to PBR textures.

**Type:** `number`

**Value:** `11`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
