# `PSYS_SRC_ANGLE_END`

This float parameter dictates the termination angle, measured in radians, for particle emission within ANGLE configurations. Should this value be less than `angle_begin`, the system will automatically reverse the intended starting and ending angles.

**Type:** `number`

**Value:** `23`
