# `OBJECT_SIT_COUNT`

When combined with ll.GetObjectDetails, this flag retrieves a count representing all agents sitting across every link belonging to the specified object. Note that if the targeted item is itself an avatar, the function will return a value of 0.

**Type:** `number`

**Value:** `38`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
