# `PARCEL_DETAILS_TP_ROUTING`

This flag, when utilized with ll.GetParcelDetails, fetches the teleport routing configuration for the parcel in question (where 0 signifies TP_ROUTING_BLOCKED, 1 indicates TP_ROUTING_LANDINGP, and 2 means TP_ROUTING_FREE; note that these rules only take effect if a landing point has been established).

**Type:** `number`

**Value:** `11`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelDetailsParam` |
