# `OBJECT_ANIMATED_SLOTS_AVAILABLE`

When calling ll.GetObjectDetails, this flag determines whether the system should retrieve the total number of available 'Animated Mesh' attachment slots for an avatar, providing a return value of zero if the specified ID does not belong to an avatar object.

**Type:** `number`

**Value:** `40`

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
