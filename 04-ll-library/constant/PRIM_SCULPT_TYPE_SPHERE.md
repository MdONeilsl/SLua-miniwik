# `PRIM_SCULPT_TYPE_SPHERE`

This sculpt type choice, intended for `PRIM_TYPE_SCULPT`, constructs a spherical sculpted primitive by joining the lateral edges and independently converging the superior and inferior surfaces.

**Type:** `number`

**Value:** `1`
