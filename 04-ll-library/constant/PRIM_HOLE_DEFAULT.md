# `PRIM_HOLE_DEFAULT`

When utilized alongside specific `PRIM_TYPE_*` flags, this parameter enables the creation of a hole that mirrors the geometry of the outer shape, using the `hole_shape` parameter for definition.

**Type:** `number`

**Value:** `0x00`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimTypeHole` |
