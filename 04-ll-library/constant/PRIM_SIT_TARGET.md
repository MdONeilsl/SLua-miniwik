# `PRIM_SIT_TARGET`

This parameter, [PRIM_SIT_TARGET, integer boolean, vector offset, rotation rot], serves for either obtaining or modifying the sit target associated with the prim. When the boolean is set to FALSE, this action deactivates the target. It differs from `ll.LinkSitTarget` in that it allows the user to explicitly define the offset as <0.0, 0.0, 0.0>.

**Type:** `number`

**Value:** `41`
