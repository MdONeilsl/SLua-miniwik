# `DATA_RATING`

Deprecated constant. When used with ll.RequestAgentData, it provides the string '0, 0, 0, 0, 0, 0'. Previously, this value returned a comma-separated list encompassing positive and negative ratings across behavior, appearance, and building before those rating types were removed from SL.

**Type:** `number`

**Value:** `4`
