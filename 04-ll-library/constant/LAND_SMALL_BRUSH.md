# `LAND_SMALL_BRUSH`

This constant represents the legacy dimensions for a small brush (2m x 2m). Developers should note that this specific value is inaccurate, and instead utilize LAND_BRUSH_SMALL.

**Type:** `number`

**Value:** `1`

## Deprecated

- **use:** LAND_BRUSH_SMALL
