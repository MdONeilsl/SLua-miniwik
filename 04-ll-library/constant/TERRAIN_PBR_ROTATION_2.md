# `TERRAIN_PBR_ROTATION_2`

This terrain parameter is utilized when calling ll.SetGroundTexture; it specifies the rotational angle, measured in radians, for the second PBR texture layer. This function is restricted to use with PBR textures exclusively.

**Type:** `number`

**Value:** `13`

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
