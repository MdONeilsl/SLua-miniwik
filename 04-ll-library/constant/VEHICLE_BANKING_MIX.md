# `VEHICLE_BANKING_MIX`

This floating-point vehicle parameter, which ranges from 0.0 (for purely static behavior) to 1.0 (for fully dynamic behavior), governs how the system blends static banking (which depends solely on roll angle) and dynamic banking (which also accounts for linear speed).

**Type:** `number`

**Value:** `39`
