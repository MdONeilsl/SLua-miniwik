# `TERRAIN_DETAIL_3`

This is a terrain parameter passed into ll.SetGroundTexture that allows one to specify the texture or material—using either a UUID, an item found in inventory, or the default values NULL_KEY/empty string—for the third level of detail on the terrain.

**Type:** `number`

**Value:** `2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
