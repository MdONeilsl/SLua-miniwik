# `OBJECT_POS`

This flag must be utilized with ll.GetObjectDetails when you need to retrieve the object's location using region-based coordinates. If the avatar calling the function is situated outside the defined region, the coordinate that is returned will be measured relative to the script's designated region area.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
