# `OBJECT_CLICK_ACTION`

When utilizing ll.GetObjectDetails, this flag allows retrieval of a primitive's click action. It provides an integer value that maps to one of the CLICK_ACTION_* constants, with a default return value of 0.

**Type:** `number`

**Value:** `28`

| Field | Value |
|---|---|
