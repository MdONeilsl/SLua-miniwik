# `WATER_WAVE_DIRECTION`

This parameter holds vector data for environmental wave direction, providing specifications for the speed and orientation of both small and large waves. Within this system, the X coordinate maps to east/west movement, and the Y coordinate maps to north/south movement.

**Type:** `number`

**Value:** `106`

|---|---|
