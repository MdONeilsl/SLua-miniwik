# `PARCEL_MEDIA_COMMAND_LOOP`

This command, utilized within `ll.ParcelMediaCommandList`, initiates playback of a media stream starting at the present frame, ensuring that the stream cycles back to its initial point upon reaching completion.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand` |
