# `PARCEL_COUNT_TOTAL`

This constant is used in conjunction with ll.GetParcelPrimCount, providing the aggregate land footprint for every object situated within the specified parcel(s), while deliberately omitting any count from temporary (temp-on-rez) items.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelPrimCountCategory` |
