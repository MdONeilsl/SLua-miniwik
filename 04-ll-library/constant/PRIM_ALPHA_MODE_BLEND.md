# `PRIM_ALPHA_MODE_BLEND`

This prim parameter controls the `PRIM_ALPHA_MODE` setting. It instructs the face to apply alpha blending when rendering its diffuse texture, provided that an alpha channel is present in the texture data. Furthermore, it serves as the default mechanism for clearing material configurations associated with a prim face.

**Type:** `number`

**Value:** `1`
