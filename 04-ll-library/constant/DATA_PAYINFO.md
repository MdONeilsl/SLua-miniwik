# `DATA_PAYINFO`

When used alongside ll.RequestAgentData, this field provides a string that holds an integer mask representing the payment status; specifically, it indicates whether the data includes PAYMENT_INFO_ON_FILE, PAYMENT_INFO_USED, or both of these statuses.

**Type:** `number`

**Value:** `8`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `AgentData` |
