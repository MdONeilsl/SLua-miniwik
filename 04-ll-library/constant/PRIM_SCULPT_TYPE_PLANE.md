# `PRIM_SCULPT_TYPE_PLANE`

This sculpt type setting for PRIM_TYPE_SCULPT ensures that no stitching or convergence occurs during generation, resulting in a smoothly flat, planar sculpted prim.

**Type:** `number`

**Value:** `3`
