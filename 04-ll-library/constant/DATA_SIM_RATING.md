# `DATA_SIM_RATING`

This constant is utilized alongside ll.RequestSimulatorData and provides the simulation's content rating as a string, which can be one of 'PG', 'MATURE', 'ADULT', or 'UNKNOWN'.

**Type:** `number`

**Value:** `7`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `SimulatorData` |
