# `PRIM_REFLECTION_PROBE_DYNAMIC`

When this flag is utilized alongside PRIM_REFLECTION_PROBE, it enables the probe to incorporate avatars into its image-based lighting reflections on the fly; however, be aware that doing so introduces a penalty to rendering performance.

**Type:** `number`

**Value:** `2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ReflectionProbeType` |
