# `PRIM_GLTF_METALLIC_ROUGHNESS`

This Prim parameter allows retrieval or modification of the GLTF occlusion/metallic/roughness override settings specific to a face. To use it, you must supply arguments including `face`, `texture`, `repeats`, `offsets`, `rotation`, `metallic_factor`, and `roughness_factor`.

**Type:** `number`

**Value:** `47`
