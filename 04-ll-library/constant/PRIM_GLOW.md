# `PRIM_GLOW`

This prim parameter, `[PRIM_GLOW, integer face, float intensity]`, allows you to retrieve or modify the glow strength applied to a specific face; note that the compiler will default to an integer value of 25 if a named constant is not applicable.

**Type:** `number`

**Value:** `25`
