# `PRIM_DESC`

A primary parameter [PRIM_DESC, string description] is used for retrieving or modifying a primitive's textual description, functionality similar to calling ll.GetObjectDesc or ll.SetObjectDesc.

**Type:** `number`

**Value:** `28`
