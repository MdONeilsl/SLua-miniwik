# `KFM_CMD_PLAY`

This command, when utilized with KFM_COMMAND within ll.SetKeyframedMotion, serves to restart movement that had been halted using KFM_CMD_STOP or temporarily suspended via KFM_CMD_PAUSE.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionCommand` |
