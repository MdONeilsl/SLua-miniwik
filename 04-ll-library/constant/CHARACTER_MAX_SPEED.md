# `CHARACTER_MAX_SPEED`

This parameter sets the maximum velocity achievable by a character, which must fall between 0.2 and 50 meters/second; its default value is 20 m/s. This setting influences both the speed used when maneuvering around dynamic obstacles and the rate of movement across objects with low walkability when operating in TRAVERSAL_TYPE_FAST mode.

**Type:** `number`

**Value:** `13`
