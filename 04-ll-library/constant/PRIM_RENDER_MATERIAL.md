# `PRIM_RENDER_MATERIAL`

Use the prim parameter [PRIM_RENDER_MATERIAL, integer face, string material] to retrieve or modify the materials assigned to a face. Be aware that utilizing this parameter will clear most PRIM_GLTF_* properties associated with the face, with exceptions for repeats, offsets, and rotation_in_radians.

**Type:** `number`

**Value:** `49`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimParam`, `PrimParamGet` |
