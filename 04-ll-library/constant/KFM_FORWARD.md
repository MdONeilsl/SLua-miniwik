# `KFM_FORWARD`

This constant specifies a playback mode for use with KFM_MODE when calling ll.SetKeyframedMotion (and is the default setting). The motion sequence will play through all available frames, progressing in order from frame 1 up to frame N, after which it will cease movement.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionMode` |
