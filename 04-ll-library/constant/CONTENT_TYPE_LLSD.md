# `CONTENT_TYPE_LLSD`

This value establishes that any future LSL HTTP server replies generated using ll.HTTPResponse must carry a 'Content-Type' header set to 'application/llsd+xml', which signifies Linden Lab Structured Data.

**Type:** `number`

**Value:** `6`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `HTTPContentType` |
