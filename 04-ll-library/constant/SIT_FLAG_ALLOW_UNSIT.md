# `SIT_FLAG_ALLOW_UNSIT`

This sit flag specifies whether an avatar, who was placed in a sitting position by an LSL script such as ll.SitOnLink, is permitted to manually unsit from its current designated seating location.

**Type:** `number`

**Value:** `0x0002`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `SitFlag` |
