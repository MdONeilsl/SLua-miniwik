# `TERRAIN_DETAIL_1`

This terrain parameter is utilized with ll.SetGroundTexture; it specifies the texture or material—which can be provided using a UUID, an item's inventory name, or by defaulting to NULL_KEY/an empty string—for the first detail layer of the ground.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
