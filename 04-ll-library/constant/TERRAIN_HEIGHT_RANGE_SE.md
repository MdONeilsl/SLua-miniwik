# `TERRAIN_HEIGHT_RANGE_SE`

This terrain parameter must be used with ll.SetGroundTexture to define the south-east vertical range for blending textures. It designates `low` as the maximum allowable height for texture 1, `high` as the minimum required height for texture 4, and facilitates mixing between textures 2 and 3 in the intermediate zone.

**Type:** `number`

**Value:** `5`
