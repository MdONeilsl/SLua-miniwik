# `PSYS_PART_INTERP_SCALE_MASK`

This particle flag dictates that the particle's size or scale will smoothly change from the value defined in its START setting to the value specified in its END setting throughout the duration of its existence.

**Type:** `number`

**Value:** `0x2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParticleFlag` |
