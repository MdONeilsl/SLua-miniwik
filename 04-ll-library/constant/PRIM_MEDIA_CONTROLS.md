# `PRIM_MEDIA_CONTROLS`

An integer value that allows retrieval or modification of the appearance style for media controls, which can be configured using either PRIM_MEDIA_CONTROLS_STANDARD or PRIM_MEDIA_CONTROLS_MINI.

**Type:** `number`

**Value:** `1`
