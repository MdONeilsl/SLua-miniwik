# `HTTP_MIMETYPE`

This parameter dictates the Media Type of the request's content. When defining text formats, remember to include a charset declaration (for instance, 'text/plain;charset=utf-8'). To simulate data submitted via standard HTML forms, utilize 'application/x-www-form-urlencoded'.

**Type:** `number`

**Value:** `1`
