# `OBJECT_ANIMATED_COUNT`

Used alongside ll.GetObjectDetails to determine specific details. When applied to an object, it provides a boolean value showing whether the object's root component has been designated as an 'Animated Mesh'. For agents, this flag reports the aggregate count of all attached 'Animated Mesh' items being worn.

**Type:** `number`

**Value:** `39`

| Field | Value |
|---|---|
