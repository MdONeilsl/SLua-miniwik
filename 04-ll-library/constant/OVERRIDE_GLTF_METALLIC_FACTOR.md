# `OVERRIDE_GLTF_METALLIC_FACTOR`

This GLTF modification setting, utilized alongside ll.SetLinkGLTFOverrides, modifies the metallic property of designated faces, allowing adjustment to any float value from 0 through 1.

**Type:** `number`

**Value:** `6`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFOverride` |
