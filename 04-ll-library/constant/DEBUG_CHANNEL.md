# `DEBUG_CHANNEL`

This constant designates a specific communication channel used solely for logging script debug information and errors. Sending messages through this identifier using functions like ll.Say, ll.Whisper, or ll.Shout will display the text both in the Script Warning/Error Window and broadcast it to the script consoles of nearby avatars.

**Type:** `number`

**Value:** `2147483647`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `Channel`, `ChannelNonPublic` |
