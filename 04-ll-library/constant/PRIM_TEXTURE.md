# `PRIM_TEXTURE`

This function retrieves or modifies the Blinn-Phong diffuse texture properties for a specific face using parameters: `[PRIM_TEXTURE, integer face, string texture, vector repeats, vector offsets, float rotation_in_radians]`.

**Type:** `number`
