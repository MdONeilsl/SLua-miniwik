# `PARCEL_DETAILS_PRIM_USED`

When calling ll.GetParcelDetails, use this flag to obtain the cumulative count of primitives used across this specific parcel and every other parcel owned by the same user within the entire simulated world (for individual breakdowns by owner, group, or temporary status, consult ll.GetParcelPrimCount).

**Type:** `number`

**Value:** `8`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelDetailsParam` |
