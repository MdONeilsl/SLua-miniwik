# `PSYS_PART_EMISSIVE_MASK`

When this particle flag is set, it renders particles with maximum brightness, ignoring any influence from general environmental light sources like sunlight. If unset, particles will be illuminated either by the existing global lighting conditions or by nearby localized point lights.

**Type:** `number`

**Value:** `0x100`
