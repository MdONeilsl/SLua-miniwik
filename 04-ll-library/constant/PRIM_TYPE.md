# `PRIM_TYPE`

This parameter, associated with the Prim object, is utilized either to retrieve or modify the geometric shape type (represented by PRIM_TYPE_*) and any parameters relevant to that specific geometry.

**Type:** `number`

**Value:** `9`

| `categories` | `PrimParam`, `PrimParamGet` |
