# `STATUS_ROTATE_X`

This status flag, which defaults to TRUE, determines if the object can physically rotate along its local X-axis. If this value is set to FALSE, rotation about the local X-axis will be prevented. Consider that a sit-and-spin device rotates around the Z axis (up) but not around either the X or Y axes.

**Type:** `number`

**Value:** `0x2`
