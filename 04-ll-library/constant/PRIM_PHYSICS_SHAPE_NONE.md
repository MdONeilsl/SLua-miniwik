# `PRIM_PHYSICS_SHAPE_NONE`

This value specifies the physical shape classification for a prim. Using it instructs the physics simulation system to completely disregard this prim, thus ensuring it does not contribute any geometry to the overall linkset's calculated physics shape. Note that applying this setting is prohibited on the root prim.

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PhysicsShapeType` |
