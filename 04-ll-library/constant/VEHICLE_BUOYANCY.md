# `VEHICLE_BUOYANCY`

This vehicle's floating-point parameter determines buoyancy across a range of -1.0 to 1.0; specifically, a value of -1.0 signifies double gravity, while 1.0 indicates complete anti-gravity effects.

**Type:** `number`

**Value:** `27`
