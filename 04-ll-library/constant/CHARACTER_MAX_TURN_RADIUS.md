# `CHARACTER_MAX_TURN_RADIUS`

This constant determines the radial distance required for a character to execute a turn while moving at the speed defined by `CHARACTER_DESIRED_TURN_SPEED` (the default value is 1.25 meters).

**Type:** `number`

**Value:** `10`
