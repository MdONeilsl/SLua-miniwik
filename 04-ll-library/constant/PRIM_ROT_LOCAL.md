# `PRIM_ROT_LOCAL`

This prim parameter, specified as [PRIM_ROT_LOCAL, rotation local_rot], allows users to read or write the local rotational state of a primitive (it functions identically to using `ll.GetLocalRot` and `ll.SetLocalRot`).

**Type:** `number`

**Value:** `29`

|---|---|
| `categories` | `PrimParam`, `PrimParamGet` |
