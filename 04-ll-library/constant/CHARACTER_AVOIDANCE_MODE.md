# `CHARACTER_AVOIDANCE_MODE`

This constant determines the type of entities that a pathfinding character must circumnavigate, including other characters, moving dynamic obstacles such as avatars, or allowing avoidance for all types. These modes are combined using bit flags; assigning AVOID_NONE will disable collision detection for both categories.

**Type:** `number`

**Value:** `5`
