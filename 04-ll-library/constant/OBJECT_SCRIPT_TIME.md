# `OBJECT_SCRIPT_TIME`

When utilizing ll.GetObjectDetails, this flag requests the mean script CPU duration in seconds consumed per single frame. The reported value represents either a three-decade moving average or, if fewer than thirty minutes have elapsed since entering the area, it provides the average from the moment of entry.

**Type:** `number`

**Value:** `12`
