# `OBJECT_SCRIPT_MEMORY`

When utilized with ll.GetObjectDetails, this flag retrieves the current allocated script memory size, or the maximum permitted size, measured in bytes, associated with the specified object or agent. Note that this reported metric undergoes recalculation at intervals ranging from 10 to 20 seconds.

**Type:** `number`

**Value:** `11`
