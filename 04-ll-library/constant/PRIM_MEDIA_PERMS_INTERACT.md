# `PRIM_MEDIA_PERMS_INTERACT`

This integer property allows you to retrieve or set the access permissions mask that controls who is permitted to interact with the media; valid scopes include (PRIM_MEDIA_PERM_ANYONE, _GROUP, _NONE, or _OWNER).

**Type:** `number`

**Value:** `13`
