# `REZ_SOUND`

The `REZ_SOUND` rez parameter requires three arguments: a string containing either an inventory name or a UUID; a float specifying the volume; and an integer determining if continuous looping should occur. This function attaches and plays a sound asset sourced from the object's inventory or specified by its UUID key, repeating indefinitely if the loop setting is true.

**Type:** number

**Value:** `9`
