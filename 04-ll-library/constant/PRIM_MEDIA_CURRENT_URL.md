# `PRIM_MEDIA_CURRENT_URL`

This String attribute can be used to retrieve or assign the current Uniform Resource Locator displayed on the selected surface, with a maximum length of 1024 characters; modifying this URL will automatically initiate media navigation.

**Type:** `number`

**Value:** `2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimMediaParam` |
