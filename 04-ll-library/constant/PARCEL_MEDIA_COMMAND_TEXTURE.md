# `PARCEL_MEDIA_COMMAND_TEXTURE`

This command is utilized in conjunction with ll.ParcelMediaCommandList or ll.ParcelMediaQuery for retrieving or modifying the media texture associated with a parcel.

**Type:** `number`

**Value:** `4`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand`, `ParcelMediaQuery` |
