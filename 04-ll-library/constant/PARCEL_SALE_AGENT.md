# `PARCEL_SALE_AGENT`

When calling ll.SetParcelForSale, this option allows specifying a particular agent's ID who has been permitted to acquire the parcel. Should no ID be provided, the purchasing rights are granted to all agents.

**Type:** `number`

**Value:** `2`
