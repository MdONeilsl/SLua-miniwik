# `SIM_STAT_PCT_CHARS_STEPPED`

This value provides the average percentage of pathfinding characters that were either updated or bypassed during a single frame, calculated across the preceding sixty seconds. This corresponds directly to the 'Characters Updated' metric displayed within the viewing application's Statistics Bar.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `SimulatorStat` |
