# `PARCEL_FLAG_LOCAL_SOUND_ONLY`

This flag, when utilized with `ll.GetParcelFlags`, determines whether the parcel imposes limitations on spatialized audio, thereby preventing external sounds from audible reception within the bounds of the parcel.

**Type:** `number`

**Value:** `0x8000`

| Field | Value |
|---|---|
