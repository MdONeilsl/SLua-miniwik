# `PARCEL_MEDIA_COMMAND_TYPE`

This command is utilized alongside `ll.ParcelMediaCommandList` or `ll.ParcelMediaQuery` for retrieving or establishing the Media Internet Mail Extensions (MIME) type associated with a parcel, such as 'text/html'.

**Type:** `number`

**Value:** `10`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand`, `ParcelMediaQuery` |
