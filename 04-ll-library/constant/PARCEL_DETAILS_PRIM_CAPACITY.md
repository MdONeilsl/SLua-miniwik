# `PARCEL_DETAILS_PRIM_CAPACITY`

When calling ll.GetParcelDetails, setting this flag allows you to obtain the cumulative prim capacity across the current parcel and every other parcel owned by the same user within the entire simulation (refer to ll.GetParcelMaxPrims for details on single-parcel or comprehensive sim-wide reporting).

**Type:** `number`

**Value:** `7`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelDetailsParam` |
