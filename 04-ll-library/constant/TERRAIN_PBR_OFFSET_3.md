# `TERRAIN_PBR_OFFSET_3`

This parameter serves as a terrain setting for `ll.SetGroundTexture`, allowing the definition of the UV offset vector (with the Z component disregarded) used when drawing terrain layer 3. Note that this feature is applicable only when using PBR textures.

**Type:** `number`

**Value:** `18`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
