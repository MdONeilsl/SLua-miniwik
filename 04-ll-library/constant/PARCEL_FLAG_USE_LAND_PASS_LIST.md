# `PARCEL_FLAG_USE_LAND_PASS_LIST`

This flag, when utilized with ll.GetParcelFlags, determines whether a given parcel imposes restrictions on entry requiring a purchasable land pass, which is typically sold using L$ currency.

**Type:** `number`

**Value:** `0x800`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelFlag` |
