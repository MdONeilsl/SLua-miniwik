# `VEHICLE_LINEAR_FRICTION_TIMESCALE`

This vehicle vector parameter determines the timescales used for calculating the exponential decay of linear velocity across the vehicle's preferred axes (specifically at, left, and up). These timescales are measured in seconds per axis and must fall within the range [0.07, infinity).

**Type:** `number`

**Value:** `16`
