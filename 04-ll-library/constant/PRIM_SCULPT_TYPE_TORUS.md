# `PRIM_SCULPT_TYPE_TORUS`

A setting used with PRIM\_TYPE\_SCULPT, defining how the sculpting process connects elements both vertically (top-to-bottom) and horizontally (left-to-right) to result in a toroidal structure for the sculpted prim.

**Type:** `number`

**Value:** `2`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimTypeSculptType` |
