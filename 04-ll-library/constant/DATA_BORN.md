# `DATA_BORN`

When used with ll.RequestAgentData, this value provides the agent's account creation date—often called 'born on'—formatted as an ISO 8601 string (YYYY-MM-DD) using Pacific Time, rather than Coordinated Universal Time (UTC).

**Type:** `number`

**Value:** `3`


## Definition fields

| Field | Value |
|---|---|
| `categories` | `AgentData` |
