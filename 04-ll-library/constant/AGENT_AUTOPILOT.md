# `AGENT_AUTOPILOT`

This constant, used alongside ll.GetAgentInfo, checks whether an avatar has activated autopilot functionality; this state can be entered either by selecting 'Go Here' while standing on the ground or through a double-click action initiating autopilot.

**Type:** `number`

**Value:** `0x2000`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `AgentInfo` |
