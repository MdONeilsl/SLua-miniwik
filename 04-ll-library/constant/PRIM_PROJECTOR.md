# `PRIM_PROJECTOR`

The parameter [PRIM_PROJECTOR] manages various light projection settings, requiring inputs for `string texture`, `float fov`, `float focus`, and `float ambiance`. It is important to note that if the prim object does not have projector configuration applied, attempting to retrieve the texture key will yield `NULL_KEY`.

**Type:** `number`

**Value:** `42`
