# `GRAVITY_MULTIPLIER`

When calling ll.SetPhysicsMaterial, this constant is used to activate an override for the gravitational force. Ensure that any assigned value falls within the range of -1.0 to +28.0.

**Type:** `number`

**Value:** `8`
