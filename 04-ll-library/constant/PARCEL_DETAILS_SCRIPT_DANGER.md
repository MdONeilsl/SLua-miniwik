# `PARCEL_DETAILS_SCRIPT_DANGER`

When calling ll.GetParcelDetails, this flag determines whether the attached script is experiencing any operational risks or limitations due to restrictions imposed on the specified parcel; refer to ll.ScriptDanger for more information.

**Type:** `number`

**Value:** `13`

| Field | Value |
|---|---|
| `categories` | `ParcelDetailsParam` |
