# `TERRAIN_PBR_SCALE_2`

This terrain parameter is utilized when calling ll.SetGroundTexture to establish the UV scaling vector for terrain layer 2. This vector represents the repeats per meter and disregards the Z component. Be aware that this setting is restricted solely to PBR textures.

**Type:** `number`

**Value:** `9`
