# `PARCEL_DETAILS_FLAGS`

When utilizing ll.GetParcelDetails, this flag specifies that the parcel flags associated with the current parcel should be retrieved; refer to ll.GetParcelFlags for a complete list and explanation of these flags.

**Type:** `number`

**Value:** `12`

| Field | Value |
|---|---|
| `categories` | `ParcelDetailsParam` |
