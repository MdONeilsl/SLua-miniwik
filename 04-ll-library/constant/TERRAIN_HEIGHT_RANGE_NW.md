# `TERRAIN_HEIGHT_RANGE_NW`

This terrain parameter is utilized with ll.SetGroundTexture to define the north-west elevation boundaries for blending textures. Specifically, it designates `low` as the upper limit of the height range for texture 1, sets `high` as the lower limit for texture 4, and handles the intermediate mixing of textures 2 and 3.

**Type:** `number`

**Value:** `6`
