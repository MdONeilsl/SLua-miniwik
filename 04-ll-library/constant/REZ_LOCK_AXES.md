# `REZ_LOCK_AXES`

The `Rez` parameter, which handles vector locks, restricts the rotation or spinning of a physical object along designated axes. To lock a specific axis, its corresponding coordinate must be set to any value other than zero.

**Type:** `number`

**Value:** `11`
