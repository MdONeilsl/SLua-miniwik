# `LAND_LARGE_BRUSH`

This constant represents an outdated measurement for a large land brush, specifically measuring 8m by 8m. Be advised that the assigned value here is wrong; developers should utilize LAND_BRUSH_LARGE instead.

**Type:** `number`

**Value:** `3`
