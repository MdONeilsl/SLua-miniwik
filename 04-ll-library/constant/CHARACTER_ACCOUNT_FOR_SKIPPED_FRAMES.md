# `CHARACTER_ACCOUNT_FOR_SKIPPED_FRAMES`

When this parameter is set to FALSE, the pathfinding character ceases efforts to make up for elapsed time when system performance drops, which might result in movement that is more consistent but could appear choppy. The default setting for this feature is TRUE.

**Type:** `number`

**Value:** `14`
