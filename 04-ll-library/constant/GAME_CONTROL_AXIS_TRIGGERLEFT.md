# `GAME_CONTROL_AXIS_TRIGGERLEFT`

This constant represents the left trigger input. It uses canonical axis index 4 and is deprecated; developers should instead utilize `GAME_CONTROL_AXIS_LEFT_TRIGGER`.

**Type:** `number`

**Value:** `4`
