# `VEHICLE_FLAG_NO_DEFLECTION_UP`

This vehicle flag stops any straight-line movement that runs along the world's Z-axis, ensuring that surface-based vehicles, for example those similar to bumper cars, cannot move upward into the air.

**Type:** `number`

**Value:** `0x1`
