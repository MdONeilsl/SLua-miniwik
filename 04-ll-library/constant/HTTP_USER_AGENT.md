# `HTTP_USER_AGENT`

Adds a user-defined string to the default LSL User-Agent header value. This string must adhere to HTTP standard syntax (for example, 'My-Script-Name/1.0'). Script errors will occur if spaces are used; therefore, hyphens should be utilized instead.

**Type:** `number`

**Value:** `7`
