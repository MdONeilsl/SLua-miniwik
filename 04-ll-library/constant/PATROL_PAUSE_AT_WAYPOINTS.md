# `PATROL_PAUSE_AT_WAYPOINTS`

This option parameter controls `ll.PatrolPoints` and defaults to FALSE. Setting this value to TRUE causes the character to slow down and make a brief stop at every waypoint it reaches; alternatively, if set to FALSE, the character will move instantly to the next point at its maximum speed without any pause.

**Type:** `number`

**Value:** `0`
