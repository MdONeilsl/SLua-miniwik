# `TERRAIN_PBR_SCALE_3`

This parameter is utilized with ll.SetGroundTexture and defines the UV scaling factor, measured in repeats per meter and disregarding the Z axis, specifically for the third terrain layer (layer 3). This feature is restricted to use with Physically Based Rendering (PBR) textures.

**Type:** `number`

**Value:** `10`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GroundTextureParam` |
