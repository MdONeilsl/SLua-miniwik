# `OVERRIDE_GLTF_BASE_DOUBLE_SIDED`

This GLTF override constant is utilized by ll.SetLinkGLTFOverrides. Setting it to TRUE ensures that the assigned texture across the associated face(s) displays with double-sided rendering.

**Type:** `number`

**Value:** `5`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFOverride` |
