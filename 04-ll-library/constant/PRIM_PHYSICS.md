# `PRIM_PHYSICS`

This prim parameter, `PRIM_PHYSICS`, which accepts an `integer` and a `boolean`, controls whether the physical behavior of the object is subject to Second Life's physics engine.

**Type:** `number`

**Value:** `3`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimParam`, `PrimParamGet` |
