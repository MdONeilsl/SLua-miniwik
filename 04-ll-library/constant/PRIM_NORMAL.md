# `PRIM_NORMAL`

This `Prim` parameter allows retrieving or modifying the settings for a face's Blinn-Phong normal map texture. It necessitates providing values for face, texture, repeats, offsets, and rotation_in_radians.

**Type:** `number`

**Value:** `37`
