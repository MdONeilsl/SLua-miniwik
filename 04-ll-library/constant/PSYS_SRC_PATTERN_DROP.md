# `PSYS_SRC_PATTERN_DROP`

This emission style generates particles directly at the emitter location, giving them zero initial movement. It bypasses any configurations set for burst radius, minimum speed, or maximum speed by setting these values to 0.0.

**Type:** `number`

**Value:** `0x01`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParticleSourcePattern` |
