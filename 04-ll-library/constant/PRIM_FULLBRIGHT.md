# `PRIM_FULLBRIGHT`

This prim parameter, `[PRIM_FULLBRIGHT, integer face, integer boolean]`, allows a user to either retrieve or change the status of full-bright rendering for a particular face.

**Type:** `number`

**Value:** `20`

| Field | Value |
|---|---|
| `categories` | `PrimParam`, `PrimParamGet` |
