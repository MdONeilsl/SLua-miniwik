# `OBJECT_PHANTOM`

This flag must be used with ll.GetObjectDetails to obtain a boolean value that confirms if phantom mode has been activated on the object. Be aware that should the object under inspection be an avatar or an attachment, the function will instead return 0.

**Type:** `number`

**Value:** `22`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
