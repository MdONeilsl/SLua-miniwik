# `CHANGED_LINK`

The count of constituent prims within the object, or any avatars seated upon it, has been modified. This event also fires when a linked object is duplicated, or when an individual prim alters its shape or type. Note that this does not trigger during attachment/detachment events, sitting/unsitting in attachments, or simple single-prim duplication.

**Type:** `number`

**Value:** `0x20`
