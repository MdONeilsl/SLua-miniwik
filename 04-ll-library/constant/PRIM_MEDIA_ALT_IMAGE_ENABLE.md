# `PRIM_MEDIA_ALT_IMAGE_ENABLE`

This boolean value allows retrieving or setting the initial image displayed on a face before media starts playing. The system's default state for this feature must be provided by the server based on the specific media type. Note that, currently, this flag does not function.

**Type:** `number`

**Value:** `0`
