# `RESTITUTION`

When utilizing ll.SetPhysicsMaterial, this constant activates the restitution property, allowing you to set a bounciness factor that replaces any previously defined value; this factor must fall within the range of 0.0 to 1.0.

**Type:** `number`

**Value:** `4`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PhysicsMaterialParam` |
