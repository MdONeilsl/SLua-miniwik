# `OBJECT_ATTACHED_POINT`

When utilized with ll.GetObjectDetails, this flag provides the numerical attachment point corresponding to an ATTACH_* constant; otherwise, it returns 0 if the specified target lacks attachment status, such as when checking an avatar or a standalone object.

**Type:** `number`

**Value:** `19`
