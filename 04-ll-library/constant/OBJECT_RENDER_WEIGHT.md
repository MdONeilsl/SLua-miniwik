# `OBJECT_RENDER_WEIGHT`

When utilizing ll.GetObjectDetails, this flag retrieves the render weight—also known as the Avatar Rendering Cost—for an avatar, which is determined by viewer reports. The return value indicates 0 for objects, -1 if the information is unknown, and it cannot exceed 500,000.

**Type:** `number`

**Value:** `24`
