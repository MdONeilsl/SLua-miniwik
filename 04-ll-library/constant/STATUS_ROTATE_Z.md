# `STATUS_ROTATE_Z`

A status indicator (which defaults to true) governing whether the object can physically rotate along its localized Z-axis. If this flag is set to false, all physical rotational movement about the local Z-axis will be prohibited.

**Type:** `number`

**Value:** `0x8`
