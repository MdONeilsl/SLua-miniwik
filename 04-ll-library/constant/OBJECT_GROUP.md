# `OBJECT_GROUP`

When utilizing ll.GetObjectDetails, this flag specifies that the function should retrieve the prim's associated group key. Note that if the entity being queried is an avatar, it will return NULL_KEY, necessitating a workaround procedure to obtain the avatar's active group information.

**Type:** `number`

**Value:** `7`

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
