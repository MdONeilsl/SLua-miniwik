# `RCERR_SIM_PERF_LOW`

This raycasting failure suggests that the request could not be fulfilled because the simulator is experiencing insufficient performance. It is recommended that users pause before attempting a retry, and they should consider lowering the complexity of the scene geometry if possible.

**Type:** `number`

**Value:** `-2`
