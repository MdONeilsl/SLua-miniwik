# `PRIM_SCULPT_FLAG_INVERT`

This flag, used with PRIM_TYPE_SCULPT, dictates that the resulting sculpted primitive should be displayed as if viewed from the interior, achieved by flipping the normal direction for every polygon.

**Type:** `number`

**Value:** `64`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PrimTypeSculptFlag` |
