# `CHANGED_ALLOWED_DROP`

The object's contents were modified when someone who isn't the owner (or when the owner modifies a non-modifiable object) placed an item inside it. Functionality for this change requires that `ll.AllowInventoryDrop` has been activated.

**Type:** `number`

**Value:** `0x40`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ChangeType` |
