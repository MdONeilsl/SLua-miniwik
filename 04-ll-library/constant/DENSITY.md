# `DENSITY`

When utilized in conjunction with `ll.SetPhysicsMaterial`, this setting signals that the density parameter is active, thereby replacing any previously set value. Its permissible range spans from 1.0 to 22587.0 kg/m³.

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `PhysicsMaterialParam` |
