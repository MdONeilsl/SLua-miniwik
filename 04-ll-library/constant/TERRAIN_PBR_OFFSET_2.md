# `TERRAIN_PBR_OFFSET_2`

This terrain setting, utilized by ll.SetGroundTexture, dictates the UV coordinates' offset vector (excluding the Z axis) when rendering the second ground texture layer. This functionality is restricted solely to PBR texture types.

**Type:** `number`

**Value:** `17`

|---|---|
