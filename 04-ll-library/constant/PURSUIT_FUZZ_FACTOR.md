# `PURSUIT_FUZZ_FACTOR`

This parameter, used with `ll.Pursue`, determines if a random target location close to the PURSUIT_OFFSET should be chosen. The acceptable range for this setting is from 0 to 1, where selecting 1 results in the highest degree of randomness. Note that a non-zero value must be set for PURSUIT_OFFSET to function correctly.

**Type:** `number`

**Value:** `3`
