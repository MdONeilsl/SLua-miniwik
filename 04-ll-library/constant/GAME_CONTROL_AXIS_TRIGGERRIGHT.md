# `GAME_CONTROL_AXIS_TRIGGERRIGHT`

This value represents the right trigger control input. It is associated with canonical axis index 5 and is marked as deprecated; developers should instead utilize `GAME_CONTROL_AXIS_RIGHT_TRIGGER`.

**Type:** `number`

**Value:** `5`

## Deprecated

- **use:** GAME_CONTROL_AXIS_RIGHT_TRIGGER
