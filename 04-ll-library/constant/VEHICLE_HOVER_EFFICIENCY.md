# `VEHICLE_HOVER_EFFICIENCY`

This floating-point vehicle parameter, which accepts values between 0.0 and 1.0, manages the dampening of hovering motion; a value of 0.0 indicates a highly oscillatory (bouncy) behavior, while 1.0 represents critical damping.

**Type:** `number`

**Value:** `25`
