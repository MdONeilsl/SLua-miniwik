# `OBJECT_RETURN_PARCEL`

When utilized with ll.ReturnObjectsByOwner, this scope flag dictates that all objects situated on the same parcel as the script and belonging to the designated owner should be returned. Note that the script's owning user must possess either estate manager privileges or ownership of the parcel for this function to work correctly.

**Type:** `number`

**Value:** `1`
