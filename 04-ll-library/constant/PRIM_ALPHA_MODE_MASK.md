# `PRIM_ALPHA_MODE_MASK`

This setting, designated as a Prim parameter for PRIM_ALPHA_MODE, handles rendering of the diffuse texture's alpha channel using a binary method at the per-pixel level. Pixels that are more opaque than the established alpha cutoff will be rendered as completely solid (fully opaque), while pixels falling below this threshold will appear entirely transparent.

**Type:** `number`

**Value:** `2`
