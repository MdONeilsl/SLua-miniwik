# `CHARACTER_TYPE`

This value sets the desired surface and ground type for the character, with `CHARACTER_TYPE_NONE` being the default setting. It is meant to categorize preferred surfaces rather than dictate movement behavior (for instance, cows typically favor type B, while sheep moved along a road might prefer type C).

**Type:** `number`

**Value:** `6`

|---|---|
