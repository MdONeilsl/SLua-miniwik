# `OBJECT_RETURN_REGION`

This scope constant, when utilized with ll.ReturnObjectsByOwner, instructs the function to retrieve every object within a region belonging to the designated owner. This functionality is restricted and requires that the executing script be owned either by the estate owner or an estate manager.

**Type:** `number`

**Value:** `4`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ReturnObjectsScope` |
