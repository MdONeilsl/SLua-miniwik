# `TERRAIN_HEIGHT_RANGE_SW`

This terrain parameter is utilized with ll.SetGroundTexture to define the south-west height range responsible for blending textures. It designates `low` as the maximum acceptable height for texture 1, sets `high` as the minimum required height for texture 4, and allows textures 2 and 3 to blend within this defined interval.

**Type:** `number`

**Value:** `4`
