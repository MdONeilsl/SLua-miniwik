# `PARCEL_MEDIA_COMMAND_DESC`

This command, when utilized with either ll.ParcelMediaCommandList or ll.ParcelMediaQuery, allows for retrieving or updating the descriptive information pertaining to a parcel's media.

**Type:** `number`

**Value:** `12`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand`, `ParcelMediaQuery` |
