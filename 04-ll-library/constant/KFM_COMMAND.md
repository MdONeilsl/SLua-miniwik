# `KFM_COMMAND`

This option flag is used with ll.SetKeyframedMotion and requires a value of KFM_CMD_STOP, KFM_CMD_PLAY, or KFM_CMD_PAUSE to control whether the motion should play, stop, or pause.

**Type:** `number`

**Value:** `0`

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionParam` |
