# `OBJECT_HOVER_HEIGHT`

When calling ll.GetObjectDetails, this flag retrieves the real-time hover height associated with an avatar (the default return value is 0.0). If the object is not an avatar or if data cannot be retrieved, it returns 0.0; note that this value does not correspond to the 'Hover' slider setting for the shape.

**Type:** `number`

**Value:** `25`
