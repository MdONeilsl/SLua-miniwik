# `OVERRIDE_GLTF_BASE_COLOR_FACTOR`

This GLTF override parameter, when utilized with `ll.SetLinkGLTFOverrides`, defines the tinting color—which must be specified in linear RGB—that applies to the base color. Developers should use `llsRGB2Linear` if they need to transform colors from Blinn-Phong representation to PBR space.

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `GLTFOverride` |
