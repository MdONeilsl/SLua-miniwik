# `PRIM_LINK_TARGET`

This `Prim` parameter, represented by `[PRIM_LINK_TARGET, integer link_target]`, allows retrieval or modification of attributes belonging to several connected prims when executing a single call to primitive parameters.

**Type:** `number`

**Value:** `34`
