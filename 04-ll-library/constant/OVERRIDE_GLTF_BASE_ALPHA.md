# `OVERRIDE_GLTF_BASE_ALPHA`

This GLTF override parameter, utilized with ll.SetLinkGLTFOverrides, determines the alpha value for a specified face or group of faces. Its effect on rendering is restricted exclusively to scenarios where the alpha mode has been configured as PRIM_GLTF_ALPHA_MODE_BLEND.

**Type:** `number`

**Value:** `2`
