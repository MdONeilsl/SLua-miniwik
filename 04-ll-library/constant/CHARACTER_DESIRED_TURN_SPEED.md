# `CHARACTER_DESIRED_TURN_SPEED`

Defines the upper limit for how fast a character can rotate around the Z-axis; by default, this speed is set to 6 meters per second. Keep in mind that this value acts as a guideline and might not be strictly observed, allowing characters to turn faster in specific scenarios.

**Type:** `number`

**Value:** `12`
