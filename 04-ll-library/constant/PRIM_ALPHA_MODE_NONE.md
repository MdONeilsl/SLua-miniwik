# `PRIM_ALPHA_MODE_NONE`

This setting, available in the Prim parameters for PRIM_ALPHA_MODE, instructs the face geometry to disregard the diffuse texture's alpha information, causing it to be rendered with full opacity (this is the default behavior if a material face does not utilize an alpha channel).

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `AlphaMode` |
