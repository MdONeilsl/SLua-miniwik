# `PRIM_GLTF_ALPHA_MODE_MASK`

This constant defines the GLTF alpha mode specifically for PRIM_GLTF_BASE_COLOR. It dictates that the material will appear completely opaque if its alpha value exceeds the defined alpha cutoff, and conversely, it will be entirely transparent if the alpha value is below this threshold.

**Type:** `number`

**Value:** `2`
