# `KFM_LOOP`

This playback setting is utilized alongside `KFM_MODE` when calling `ll.SetKeyframedMotion`. The mode executes the stored keyframes in order from frame 1 up to frame N, subsequently returning to its starting point, and repeating this cycle perpetually.

**Type:** `number`

**Value:** `1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `KeyframedMotionMode` |
