# `PUBLIC_CHANNEL`

This integer constant designates the public, local chat channel. When provided to communication functions like ll.Say, ll.Whisper, or ll.Shout, it causes text to appear in the publicly audible chat visible to surrounding users and objects.

**Type:** `number`

**Value:** `0`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `Channel` |
