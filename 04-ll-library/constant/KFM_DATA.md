# `KFM_DATA`

This option flag is used with `ll.SetKeyframedMotion`. It requires a bitwise OR combination of `KFM_TRANSLATION` and `KFM_ROTATION` to indicate which keyframe data is being set. Note that if this flag is omitted, you must supply both rotation and translation data.

**Type:** `number`

**Value:** `2`
