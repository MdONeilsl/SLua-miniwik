# `SKY_SUN`

This parameter governs various environmental settings for the sun, including its rotational state, size scaling, color properties, default texture status, directional vector, ambient coloration, and diffuse coloration.

**Type:** `number`

**Value:** `14`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `EnvironmentParamReadOnly`, `EnvironmentParam` |
