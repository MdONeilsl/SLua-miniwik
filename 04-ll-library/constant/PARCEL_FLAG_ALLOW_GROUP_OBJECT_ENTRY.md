# `PARCEL_FLAG_ALLOW_GROUP_OBJECT_ENTRY`

This flag, when utilized with ll.GetParcelFlags, determines whether a specific parcel limits object entry exclusively to items owned by either the group or the individual owner.

**Type:** `number`

**Value:** `0x10000000`

| Field | Value |
|---|---|
