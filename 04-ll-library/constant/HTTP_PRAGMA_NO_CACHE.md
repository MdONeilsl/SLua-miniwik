# `HTTP_PRAGMA_NO_CACHE`

Determines if the 'Pragma: no-cache' header should be included in the HTTP request. If `SendHeader` is set to TRUE by default, the header will be transmitted; conversely, setting it to FALSE will ensure its omission.

**Type:** `number`

**Value:** `6`
