# `SKY_GAMMA`

This constant dictates the gamma factor used throughout the environment, though note that starting from viewer 7.0+, this function is represented by the HDR Scale setting within the EEP editor.

**Type:** `number`

**Value:** `5`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `EnvironmentParamReadOnly`, `EnvironmentParam` |
