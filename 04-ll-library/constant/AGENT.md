# `AGENT`

This value represents agents (avatars). When used within ll.DetectedType, it signifies an avatar. Furthermore, when utilized in ll.Sensor or ll.SensorRepeat, it performs a search for avatars using a legacy name approach which is functionally identical to AGENT_BY_LEGACY_NAME; however, developers are encouraged to use AGENT_BY_LEGACY_NAME instead.

**Type:** `number`

**Value:** `0x1`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `DetectType` |
