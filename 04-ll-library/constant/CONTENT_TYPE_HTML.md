# `CONTENT_TYPE_HTML`

This constant configures the 'Content-Type' header for all following LSL HTTP server replies sent using ll.HTTPResponse, assigning it the value 'text/html'. This setting is effective exclusively when dealing with embedded browsers viewing content that belongs to the viewer; otherwise, a fallback to 'text/plain' will occur.

**Type:** `number`

**Value:** `1`

| Field | Value |
|---|---|
| `categories` | `HTTPContentType` |
