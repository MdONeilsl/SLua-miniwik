# `OBJECT_PERMS_COMBINED`

When utilizing ll.GetObjectDetails, this flag allows for the retrieval of an aggregate permission set that combines both the object's inherent permissions and those applied to every item within its inventory, resulting in a value expressed as five distinct integers.

**Type:** `number`

**Value:** `54`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ObjectDetailsParam` |
