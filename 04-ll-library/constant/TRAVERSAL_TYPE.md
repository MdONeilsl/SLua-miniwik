# `TRAVERSAL_TYPE`

This pathfinding setting determines how a character moves when traversing the environment. It must be set to one of three types: TRAVERSAL_TYPE_SLOW (which is the default value), _FAST, or _NONE.

**Type:** `number`

**Value:** `7`
