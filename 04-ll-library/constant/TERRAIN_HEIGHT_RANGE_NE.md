# `TERRAIN_HEIGHT_RANGE_NE`

This terrain parameter is utilized with ll.SetGroundTexture to define the north-east height span governing texture blending. Specifically, it sets `low` as the maximum acceptable height for texture 1, `high` as the minimum required height for texture 4, and manages the interpolation between textures 2 and 3 within this range.

**Type:** `number`

**Value:** `7`
