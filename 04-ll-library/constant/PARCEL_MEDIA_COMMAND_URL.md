# `PARCEL_MEDIA_COMMAND_URL`

This command facilitates retrieving or updating the URL for a parcel's associated media when utilized alongside `ll.ParcelMediaCommandList` or `ll.ParcelMediaQuery`.

**Type:** `number`

**Value:** `5`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `ParcelMediaCommand`, `ParcelMediaQuery` |
