# `REQUIRE_LINE_OF_SIGHT`

This option flag in `ll.Pursue` determines if the character must have an unobstructed view of the target while pursuing them. If this setting is enabled, the system will ignore locations that are obscured by solid objects.

**Type:** `number`

**Value:** `2`
