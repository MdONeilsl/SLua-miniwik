# `STATUS_BLOCK_GRAB`

This status flag, which defaults to `FALSE`, prevents click-and-drag grabbing actions when applied to either unlinked prims or the main prim of a linkset. It is helpful for ensuring that physical objects cannot be easily moved or altered.

**Type:** `number`

**Value:** `0x40`
