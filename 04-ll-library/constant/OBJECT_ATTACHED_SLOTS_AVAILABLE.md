# `OBJECT_ATTACHED_SLOTS_AVAILABLE`

This flag, when utilized with ll.GetObjectDetails, retrieves the number of currently available attachment slots for an avatar. The function will return a value of 0 if the specified ID does not belong to an avatar, or if all attachment slots are already occupied.

**Type:** `number`

**Value:** `35`
