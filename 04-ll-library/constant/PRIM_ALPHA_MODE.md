# `PRIM_ALPHA_MODE`

This prim parameter controls various aspects of how diffuse texture alpha is rendered. Setting it requires specifying the face, an alpha_mode value (which can be PRIM_ALPHA_MODE_BLEND, _NONE, _MASK, or _EMISSIVE), and also includes the alpha_cutoff parameter, which is only relevant when using _MASK.

**Type:** `number`

**Value:** `38`
