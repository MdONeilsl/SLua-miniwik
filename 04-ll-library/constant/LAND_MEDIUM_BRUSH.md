# `LAND_MEDIUM_BRUSH`

This constant represents an older, medium-sized land brush area measuring 4m by 4m. Be advised that this value is outdated and inaccurate; you should utilize LAND_BRUSH_MEDIUM instead for correct functionality.

**Type:** `number`

**Value:** `2`

## Deprecated
