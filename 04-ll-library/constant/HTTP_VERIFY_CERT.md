# `HTTP_VERIFY_CERT`

When this setting is enabled (TRUE), the system requires that the SSL certificate presented by the server can be validated against a recognized Certificate Authority during HTTPS communications. Conversely, if it is disabled (FALSE), any type of SSL certificate will be considered acceptable.

**Type:** `number`

**Value:** `3`
