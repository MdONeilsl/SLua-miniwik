# `SIT_FLAG_SIT_TARGET`

This is a read-only flag that signifies if the prim possesses an active sit target. To set or clear this flag, use either `ll.SitTarget`, `ll.LinkSitTarget`, or `PRIM_SIT_TARGET`; alternatively, it can be queried using `ll.GetLinkSitFlags` or `PRIM_SIT_FLAGS`.

**Type:** `number`

**Value:** `0x0001`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `SitFlag` |
