# `REZ_SOUND_COLLIDE`

This Rez parameter takes a string (either a name or a UUID) and a float value, used to define a specific sound that will be played when this object collides with other objects, the floor, or any avatars nearby.

**Type:** `number`

**Value:** `10`

## Definition fields

| Field | Value |
|---|---|
| `categories` | `RezParam` |
