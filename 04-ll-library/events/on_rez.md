# `on_rez`

```lua
on_rez(start_param: number) -> ()
```

This event fires when an object is placed in the world by a user or script. It also executes upon attaching, either at login time or directly from inventory.

## Arguments

| Name | Type | Description |
|---|---|---|
| `start_param` | `number` | The numerical value provided when the object is placed in the world. |

**Returns:** `()`
