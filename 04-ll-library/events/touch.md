# `touch`

```lua
touch(detected: {DetectedEvent}) -> ()
```

This event fires repeatedly while a user hold click over this object. The handler receives a table detailing every entity currently touching the item.

## Arguments

| Name | Type | Description |
|---|---|---|
| `detected` | `{DetectedEvent}` | A table containing data for all detected agents and objects. |

**Returns:** `()`
