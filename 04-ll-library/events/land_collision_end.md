# `land_collision_end`

```lua
land_collision_end(pos: vector) -> ()
```

This event fires from the primary primitive when an attached avatar or object ceases touching the ground. The handler receives the coordinates where this physical contact ended.

## Arguments

| Name | Type | Description |
|---|---|---|
| `pos` | `vector` | The coordinates where contact with the floor ended. |

**Returns:** `()`
