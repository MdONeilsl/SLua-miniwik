# `touch_end`

```lua
touch_end(detected: {DetectedEvent}) -> ()
```

This function executes when user release left mouse button while the cursore is still over the object. The handler receives data detailing every agent involved in the connection.

## Arguments

| Name | Type | Description |
|---|---|---|
| `detected` | `{DetectedEvent}` | A collection of event structures for all connected agents. |

**Returns:** `()`
