# `land_collision_start`

```lua
land_collision_start(pos: vector) -> ()
```

This function executes within the root primitive when something (like an avatar or item) makes initial contact with the floor, providing the precise location of that impact.

## Arguments

| Name | Type | Description |
|---|---|---|
| `pos` | `vector` | The coordinates where contact was made with the terrain. |

**Returns:** `()`
