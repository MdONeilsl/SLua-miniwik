# `collision`

```lua
collision(detected: {DetectedEvent}) -> ()
```

This function fires repeatedly as any object or avatar makes contact with the prim holding the script. It provides details about every detected collider.

## Arguments

| Name | Type | Description |
|---|---|---|
| `detected` | `{DetectedEvent}` | A collection of event details for every object that has collided. |

**Returns:** `()`
