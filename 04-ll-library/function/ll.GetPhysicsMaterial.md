# `ll.GetPhysicsMaterial`

```lua
ll.GetPhysicsMaterial() -> {number}
```

Returns a list structured as [float gravity_multiplier, float restitution, float friction, float density] that specifies the physical properties of the object.

## Arguments

_No arguments._

**Returns:** `{number}`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `physics`, `prim` |
