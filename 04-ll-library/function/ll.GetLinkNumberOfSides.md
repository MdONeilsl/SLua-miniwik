# `ll.GetLinkNumberOfSides`

```lua
ll.GetLinkNumberOfSides(link: number) -> number
```

Returns the count of faces as an integer for the prim referenced by the provided link.


## Arguments

| Name | Type | Description |
|---|---|---|
| `link` | `number` | Link number (1 for root, >1 for children) or a LINK_* flag. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset`, `prim_appearance` |
