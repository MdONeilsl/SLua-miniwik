# `ll.GetPermissionsKey`

```lua
ll.GetPermissionsKey() -> uuid
```

This function returns the unique identifier (UUID) of the avatar that most recently granted or denied permission to the script, or NULL_KEY if the permission request was not acted upon or was canceled.


## Arguments

_No arguments._

**Returns:** `uuid`
