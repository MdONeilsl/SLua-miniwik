# `ll.GetExperienceErrorMessage`

```lua
ll.GetExperienceErrorMessage(error: number) -> string
```

Provides a textual explanation for the given experience error code, or returns the message associated with XP_ERROR_UNKNOWN_ERROR if the provided code is not valid.

## Arguments

| Name | Type | Description |
|---|---|---|
| `error` | `number` | XP_ERROR_* error code constant to translate. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `experience` |
