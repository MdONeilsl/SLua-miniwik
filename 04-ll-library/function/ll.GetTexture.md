# `ll.GetTexture`

```lua
ll.GetTexture(face: number) -> string
```

Returns a string that identifies the Blinn-Phong diffuse texture applied to the specified face, which will be the inventory name if the texture is stored in the prim’s inventory, or its key UUID if not.

## Arguments

| Name | Type | Description |
|---|---|---|
| `face` | number | Face number or ALL_SIDES. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `prim_appearance` |
