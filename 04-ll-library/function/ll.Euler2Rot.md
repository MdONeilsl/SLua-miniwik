# `ll.Euler2Rot`

```lua
ll.Euler2Rot(v: vector) -> quaternion
```

Converts a vector containing Euler angles (measured in radians) into its corresponding quaternion representation.


## Arguments

| Name | Type | Description |
|---|---|---|
| `v` | `vector` | Vector of Euler angles to convert, in radians. |

**Returns:** `quaternion`
