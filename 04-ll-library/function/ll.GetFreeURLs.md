# `ll.GetFreeURLs`

```lua
ll.GetFreeURLs() -> number
```

This function returns an integer indicating how many HTTP URLs are still available for use, whether the object is attached to an owner or unattached to a region.


## Arguments

_No arguments._

**Returns:** `number`

|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `script`, `web` |
