# `ll.GetTime`

```lua
ll.GetTime() -> number
```

This function returns a floating-point value indicating the amount of time, in seconds with subsecond accuracy, that has passed since the script began, was reset, or the last invocation of ll.ResetTime or ll.GetAndResetTime.


## Arguments

_No arguments._

**Returns:** `number`
