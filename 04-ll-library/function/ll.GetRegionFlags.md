# `ll.GetRegionFlags`

```lua
ll.GetRegionFlags() -> number
```

Returns an integer value that is a bitfield indicating which region flags (REGION_FLAG_*) are active for the region enclosing the object.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region` |
