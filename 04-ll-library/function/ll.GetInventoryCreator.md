# `ll.GetInventoryCreator`

```lua
ll.GetInventoryCreator(item: string) -> uuid
```

For a given item within a prim's inventory, this function retrieves the unique identifier (UUID) of the user who created it.

## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `string` | Name of the item in the prim's inventory. |

**Returns:** `uuid`
