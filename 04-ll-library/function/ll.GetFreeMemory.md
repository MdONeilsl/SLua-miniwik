# `ll.GetFreeMemory`

```lua
ll.GetFreeMemory() -> number
```

Returns an integer indicating the amount of free memory, in bytes, that is currently available for the script to use.


## Arguments

_No arguments._

**Returns:** `number`

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `script` |
