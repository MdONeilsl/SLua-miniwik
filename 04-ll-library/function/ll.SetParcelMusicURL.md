# `ll.SetParcelMusicURL`

```lua
ll.SetParcelMusicURL(url: string) -> ()
```

Configures the parcel's streaming audio source by assigning a URL to the music track. The script must be owned by the parcel's landowner or land group to execute this function.

## Arguments

| Name | Type | Description |
|---|---|---|
| `url` | `string` | Streaming audio URL string. |

**Returns:** `()`
