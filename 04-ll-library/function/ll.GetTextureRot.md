# `ll.GetTextureRot`

```lua
ll.GetTextureRot(face: number) -> number
```

This function returns the texture rotation angle in radians for the specified face.


## Arguments

| Name | Type | Description |
|---|---|---|
| `face` | `number` | Face number or ALL_SIDES. |

**Returns:** `number`
