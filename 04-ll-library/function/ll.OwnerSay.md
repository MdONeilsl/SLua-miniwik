# `ll.OwnerSay`

```lua
ll.OwnerSay(msg: string) -> ()
```

Transmits the specified message privately to the owner of the object, provided the owner is located within the same region at the time of sending.


## Arguments

| Name | Type | Description |
|---|---|---|
| `msg` | `string` | Text message string to send to the object owner. |

**Returns:** `()`
