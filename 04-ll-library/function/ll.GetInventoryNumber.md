# `ll.GetInventoryNumber`

```lua
ll.GetInventoryNumber(type: number) -> number
```

Returns the number of items matching the given type (INVENTORY_*) currently held in the prim's inventory.

## Arguments

| Name | Type | Description |
|---|---|---|
| type | number | — |

**Returns:** `number`

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
