# `ll.GetInventoryName`

```lua
ll.GetInventoryName(type: number, index: number) -> string
```

Retrieves the name of the inventory item corresponding to the given type (INVENTORY_*) and index position.

## Arguments

| Name | Type | Description |
|---|---|---|
| `type` | `number` | |
| `index` | `number` | Index of the item of that type. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim_inventory` |
