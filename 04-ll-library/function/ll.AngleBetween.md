# `ll.AngleBetween`

```lua
ll.AngleBetween(a: quaternion, b: quaternion) -> number
```

Computes the angular difference in radians between the two given rotations, start_rot and end_rot.


## Arguments

| Name | Type | Description |
|---|---|---|
| `a` | `quaternion` | Starting rotation. |
| `b` | `quaternion` | Ending rotation. |

**Returns:** `number`
