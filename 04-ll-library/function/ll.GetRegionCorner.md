# `ll.GetRegionCorner`

```lua
ll.GetRegionCorner() -> vector
```

This function returns a vector in meters that specifies the global grid position of the region’s south-west corner, with the Z coordinate fixed at 0.0.

## Arguments

_No arguments._

**Returns:** `vector`

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region` |
