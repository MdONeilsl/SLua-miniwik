# `ll.GetTorque`

```lua
ll.GetTorque() -> vector
```

This function returns a vector that indicates the current torque force applied to the object, provided the object has physical properties.

## Arguments

_No arguments._

**Returns:** `vector`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `movement`, `physics` |
