# `ll.EscapeURL`

```lua
ll.EscapeURL(url: string) -> string
```

Converts the given URL string into its percent-encoded form, substituting spaces with '%20' and any non-alphanumeric characters with their corresponding '%xx' hexadecimal representation based on UTF-8 encoding.


## Arguments

| Name | Type | Description |
|---|---|---|
| `url` | `string` | Unescaped URL string to escape. |

**Returns:** `string`
