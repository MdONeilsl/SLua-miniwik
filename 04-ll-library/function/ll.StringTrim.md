# `ll.StringTrim`

```lua
ll.StringTrim(src: string, type: number) -> string
```

Creates a new string by removing leading, trailing, or both kinds of whitespace—such as spaces, tabs, and line breaks—from the input string, based on the trim mode specified.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `string` | String to trim. |
| `type` | `number` | The trimming mode (e.g., 0 for both ends, 1 for leading only). |

**Returns:** `string`
