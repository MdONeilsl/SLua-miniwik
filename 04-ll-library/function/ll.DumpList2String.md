# `ll.DumpList2String`

```lua
ll.DumpList2String(src: list, separator: string) -> string
```

Converts the given list into a single string by joining its elements with the specified separator between each item.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | Source list to convert. |
| `separator` | `string` | Separator string to place between list entries. |

**Returns:** `string`
