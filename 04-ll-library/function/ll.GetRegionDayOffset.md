# `ll.GetRegionDayOffset`

```lua
ll.GetRegionDayOffset() -> number
```

Returns an integer indicating the time offset in seconds that is applied to determine the current environmental time within the region.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region`, `time` |
