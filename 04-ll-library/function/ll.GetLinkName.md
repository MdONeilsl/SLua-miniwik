# `ll.GetLinkName`

```lua
ll.GetLinkName(link: number) -> string
```

Returns the name as a string of the prim that is linked via the specified link number.

## Arguments

| Name | Type | Description |
|---|---|---|
| `link` | `number` | Link number (1 for root, >1 for children) or a LINK_* flag. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset` |
