# `ll.LinksetDataCountFound`

```lua
ll.LinksetDataCountFound(pattern: string) -> number
```

Counts how many keys within the linkset datastore correspond to the given regular expression pattern.


## Arguments

| Name | Type | Description |
|---|---|---|
| `pattern` | `string` | Regular expression (regex) matching the keys to count. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `data_storage`, `linkset`, `linkset_data` |
