# `ll.GetRegionMoonRotation`

```lua
ll.GetRegionMoonRotation() -> quaternion
```

This function returns a rotation value that defines how the moon is oriented within the region, adjusted for altitude tracking.

## Arguments

_No arguments._

**Returns:** `quaternion`

| Field | Value |

| `sleep` | `0.0` |
