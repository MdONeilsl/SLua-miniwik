# `ll.DataSizeKeyValue`

```lua
ll.DataSizeKeyValue() -> uuid
```

Initiates an asynchronous operation to fetch the current usage and total allocated data storage for the experience, returning a handle used to track the dataserver event.


## Arguments

_No arguments._

**Returns:** `uuid`

| `sleep` | `0.0` |
