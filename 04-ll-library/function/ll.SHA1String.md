# `ll.SHA1String`

```lua
ll.SHA1String(src: string) -> string
```

Computes and returns a 40-character hexadecimal string that is the SHA-1 cryptographic hash of the input string.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `string` | Source string to hash. |

**Returns:** `string`
