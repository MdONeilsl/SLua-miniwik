# `ll.GroundNormal`

```lua
ll.GroundNormal(offset: vector) -> vector
```

Returns a vector that indicates the orientation of the ground surface directly beneath the current position, adjusted by the specified offset vector.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset relative to the prim's position, expressed in local coordinates. |

**Returns:** `vector`
