# `ll.SetSoundRadius`

```lua
ll.SetSoundRadius(radius: number) -> ()
```

Sets the maximum distance in meters within which attached and triggered scripted sounds will be audible.


## Arguments

| Name | Type | Description |
|---|---|---|
| `radius` | `number` | Maximum distance in meters at which the sounds can be heard. |

**Returns:** `()`
