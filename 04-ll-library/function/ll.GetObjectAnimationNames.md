# `ll.GetObjectAnimationNames`

```lua
ll.GetObjectAnimationNames() -> {string}
```

This function returns a list of strings, each corresponding to either the name or UUID of an animation that is currently playing on the object.


## Arguments

_No arguments._

**Returns:** `{string}`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `object_animation` |
