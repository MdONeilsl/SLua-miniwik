# `ll.SetTouchText`

```lua
ll.SetTouchText(text: string) -> ()
```

When the right-click context menu is invoked, it will show the provided string instead of the default 'Touch' label.


## Arguments

| Name | Type | Description |
|---|---|---|
| `text` | `string` | Context menu text to display. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim_properties`, `touch`, `user_interface` |
