# `ll.SetCameraParams`

```lua
ll.SetCameraParams(rules: list) -> ()
```

Applies a set of camera configuration rules at once via a list of key-value pairs. This function demands the PERMISSION_CONTROL_CAMERA runtime permission to execute.

## Arguments

| Name | Type | Description |
|---|---|---|
| `rules` | `list` | A strided list of rules and data pairs configuring the camera. |

**Returns:** `()`

| sleep | 0.0 |
