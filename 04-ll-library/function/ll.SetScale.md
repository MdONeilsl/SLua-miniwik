# `ll.SetScale`

```lua
ll.SetScale(size: vector) -> ()
```

Adjusts the physical dimensions of the prim hosting the script to match the specified size vector.

## Arguments

| Name | Type | Description |
|---|---|---|
| `size` | `vector` | Target size vector. |

**Returns:** `()`

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `prim_appearance` |
