# `ll.DetectedDamage`

```lua
ll.DetectedDamage(number: number) -> {any}
```

For the given event index, this function returns a list detailing pending damage data, encompassing the current damage value, the type of damage, and the initial damage amount that was applied.

## Arguments

| Name | Type | Description |
|---|---|---|
| `number` | number | Index of the detection information. |

**Returns:** `{any}`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `combat`, `detected` |
