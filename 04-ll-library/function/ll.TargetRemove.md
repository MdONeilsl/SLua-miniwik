# `ll.TargetRemove`

```lua
ll.TargetRemove(handle: number) -> ()
```

Deletes the positional target identified by the integer handle previously obtained from ll.Target.


## Arguments

| Name | Type | Description |
|---|---|---|
| `handle` | `number` | Integer target handle returned by ll.Target to remove. |

**Returns:** `()`
