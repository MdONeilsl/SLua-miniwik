# `ll.GetStartString`

```lua
ll.GetStartString() -> string
```

When an object is rez'd using ll.RezObjectWithParams, this function returns the initialization string provided via REZ_PARAM_STRING; it returns an empty string if the object is rezzed by an agent.

## Arguments

_No arguments._

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `rez`, `script` |
