# `ll.GetAnimationList`

```lua
ll.GetAnimationList(avatar: uuid) -> {uuid}
```

This function provides a list of UUIDs corresponding to all animations that are currently active and playing on the given avatar.


## Arguments

| Name | Type | Description |
|---|---|---|
| `avatar` | `uuid` | UUID of the avatar in the same region. |

**Returns:** `{uuid}`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `avatar_animation`, `permissions` |
