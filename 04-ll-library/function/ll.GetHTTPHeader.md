# `ll.GetHTTPHeader`

```lua
ll.GetHTTPHeader(request_id: uuid, header: string) -> string
```

Returns the value of the specified HTTP header for the given request_id as a string.


## Arguments

| Name | Type | Description |
|---|---|---|
| `request_id` | `uuid` | Unique key of the HTTP request. |
| `header` | `string` | Lowercase name of the HTTP header to retrieve. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `web` |
