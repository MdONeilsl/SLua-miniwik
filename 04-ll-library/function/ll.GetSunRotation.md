# `ll.GetSunRotation`

```lua
ll.GetSunRotation() -> quaternion
```

This function returns a rotation value that defines the sun's orientation relative to the current parcel and its altitude track. If no custom parcel environment is configured, it defaults to the region’s predefined sun rotation.


## Arguments

_No arguments._

**Returns:** `quaternion`
