# `ll.GetHealth`

```lua
ll.GetHealth(id: uuid) -> number
```

Returns the current health value as a floating-point number for the specified avatar or object, identified by its key.


## Arguments

| Name | Type | Description |
|---|---|---|
| `id` | uuid | UUID of the agent or object to query. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `combat` |
