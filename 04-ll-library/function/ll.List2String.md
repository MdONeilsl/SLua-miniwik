# `ll.List2String`

```lua
ll.List2String(src: list, index: number) -> string
```

Retrieves the string element located at the specified index within the given list. If the index is beyond the valid range, it returns an empty string.

## Arguments

| Name | Type | Description |
|---|---|---|
| src | list | Source list containing the element of interest. |
| index | number | Zero-based index of the entry. |

**Returns:** `string`

## Deprecated

- **reason:** Use '[]' and 'tostring' instead.
