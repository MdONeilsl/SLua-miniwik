# `ll.PreloadSound`

```lua
ll.PreloadSound(sound: string | uuid) -> ()
```

Triggers nearby viewers within range to load the designated sound from the object's inventory, ensuring no playback lag occurs.


## Arguments

| Name | Type | Description |
|---|---|---|
| `sound` | `string | uuid` | Name of the sound in the prim's inventory, or a UUID. |

**Returns:** `()`
