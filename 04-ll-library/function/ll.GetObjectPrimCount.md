# `ll.GetObjectPrimCount`

```lua
ll.GetObjectPrimCount(prim: uuid) -> number
```

Returns the count of prims as an integer, corresponding to the total number of prims within the same object that contains the given prim.


## Arguments

| Name | Type | Description |
|---|---|---|
| `prim` | `uuid` | UUID of the prim in the same region. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `object` |
