# `ll.ListenRemove`

```lua
ll.ListenRemove(handle: number) -> ()
```

Removes the listener identified by the provided integer handle.

## Arguments

| Name | Type | Description |
|---|---|---|
| `handle` | `number` | Integer listener handle returned by ll.Listen to remove. |

**Returns:** `()`
