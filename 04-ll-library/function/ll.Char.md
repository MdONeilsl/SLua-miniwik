# `ll.Char`

```lua
ll.Char(val: number) -> string
```

Creates and returns a string consisting of a single character, derived from the specified Unicode codepoint value.


## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Unicode codepoint integer (ordinal) to convert. |

**Returns:** `string`
