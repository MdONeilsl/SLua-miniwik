# `ll.Log10`

```lua
ll.Log10(val: number) -> number
```

Computes the base-10 logarithm of the given value; for negative inputs, it yields 0.0.


## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Number to compute the logarithm of. |

**Returns:** `number`

## Deprecated

- **use:** math.log10
- **reason:** Double precision; fastcall.
