# `ll.GetObjectDesc`

```lua
ll.GetObjectDesc() -> string
```

This function retrieves and returns a string that describes the prim hosting the current script.


## Arguments

_No arguments._

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `prim_properties` |
