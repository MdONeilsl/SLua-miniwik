# `ll.Linear2sRGB`

```lua
ll.Linear2sRGB(color: vector) -> vector
```

Converts a color vector from linear RGB space to the sRGB color space.


## Arguments

| Name | Type | Description |
|---|---|---|
| `color` | `vector` | Color vector in the linear RGB space to convert. |

**Returns:** `vector`
