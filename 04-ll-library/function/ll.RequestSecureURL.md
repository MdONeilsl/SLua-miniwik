# `ll.RequestSecureURL`

```lua
ll.RequestSecureURL() -> uuid
```

Initiates an asynchronous HTTPS request using SSL on port 12043 for this object, which will emit an http_request event upon completion. The function returns a key handle for querying the request status.


## Arguments

_No arguments._

**Returns:** `uuid`
