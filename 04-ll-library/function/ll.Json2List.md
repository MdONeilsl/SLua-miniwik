# `ll.Json2List`

```lua
ll.Json2List(src: string) -> {any}
```

Converts the provided JSON string into a list containing its top-level values.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `string` | JSON string to parse. |

**Returns:** `{any}`
