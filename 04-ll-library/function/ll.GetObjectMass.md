# `ll.GetObjectMass`

```lua
ll.GetObjectMass(id: uuid) -> number
```

Returns the mass as a floating-point value for the avatar or object identified by the given key.


## Arguments

| Name | Type | Description |
|---|---|---|
| `id` | `uuid` | UUID of the avatar or object to query. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `object`, `physics` |
