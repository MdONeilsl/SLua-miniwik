# `ll.GetSPMaxMemory`

```lua
ll.GetSPMaxMemory() -> number
```

This function returns an integer value indicating the peak memory consumption (measured in bytes) of the script during the most recent memory profiling session, but only if PROFILE_SCRIPT_MEMORY has been invoked prior to calling this function.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `script` |
