# `ll.EjectFromLand`

```lua
ll.EjectFromLand(avatar: uuid) -> ()
```

Removes the specified avatar from any land or parcel that is owned by the owner of the calling object, whether that owner is a group or a resident.


## Arguments

| Name | Type | Description |
|---|---|---|
| `avatar` | `uuid` | UUID of the avatar in the same region. |

**Returns:** `()`
