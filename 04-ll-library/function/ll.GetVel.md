# `ll.GetVel`

```lua
ll.GetVel() -> vector
```

This function returns a vector that indicates the object's velocity in meters per second, measured relative to the global region coordinate system. When applied to physical objects, it specifically returns the velocity of the object’s center of mass.

## Arguments

_No arguments._

**Returns:** `vector`
