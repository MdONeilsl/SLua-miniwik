# `ll.GetInventoryType`

```lua
ll.GetInventoryType(item: string) -> number
```

Returns an integer corresponding to the INVENTORY_* category for the specified item in the prim's inventory.

## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `string` | Name of the item in the prim's inventory. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim_inventory` |
