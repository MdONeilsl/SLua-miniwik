# `ll.SetCameraAtOffset`

```lua
ll.SetCameraAtOffset(offset: vector) -> ()
```

Defines the local coordinate offset vector that determines where a seated avatar’s camera will be directed.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset position vector in local coordinates relative to the prim. |

**Returns:** `()`
