# `ll.ClearCameraParams`

```lua
ll.ClearCameraParams() -> ()
```

Restores all camera settings to their default state and disables any scripted camera control. This function necessitates the PERMISSION_CONTROL_CAMERA runtime permission, which is automatically provided to objects that are attached to or sat on by an avatar.


## Arguments

_No arguments._

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `camera`, `permissions` |
