# `ll.GetTextureOffset`

```lua
ll.GetTextureOffset(face: number) -> vector
```

This function returns a vector that specifies the texture offset for the given face, with components corresponding to the X (horizontal U) and Y (vertical V) axes; the Z component is not used.

## Arguments

| Name | Type | Description |
|---|---|---|
| `face` | `number` | Face number or ALL_SIDES. |

**Returns:** `vector`
