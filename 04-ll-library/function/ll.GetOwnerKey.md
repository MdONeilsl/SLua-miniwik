# `ll.GetOwnerKey`

```lua
ll.GetOwnerKey(id: uuid) -> uuid
```

Given a prim's UUID, this function retrieves and returns the UUID of the owner associated with that prim.

## Arguments

| Name | Type | Description |
|---|---|---|
| `id` | `uuid` | UUID of the prim in the same region. |

**Returns:** `uuid`
