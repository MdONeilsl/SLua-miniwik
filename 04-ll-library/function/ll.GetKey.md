# `ll.GetKey`

```lua
ll.GetKey() -> uuid
```

This function retrieves the unique identifier (UUID) of the primitive object that hosts the current script.


## Arguments

_No arguments._

**Returns:** `uuid`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `uuid` |
