# `ll.RotTargetRemove`

```lua
ll.RotTargetRemove(handle: number) -> ()
```

Deletes the rotational target previously registered via ll.RotTarget using the provided integer handle.

## Arguments

| Name | Type | Description |
|---|---|---|
| `handle` | `number` | Integer target handle returned by ll.RotTarget to remove. |

**Returns:** `()`
