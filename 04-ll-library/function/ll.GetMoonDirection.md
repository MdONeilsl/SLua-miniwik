# `ll.GetMoonDirection`

```lua
ll.GetMoonDirection() -> vector
```

Returns a normalized vector indicating the current orientation of the parcel's moon, adjusted for its altitude. If no custom parcel environment is active, it defaults to the region's moon direction.


## Arguments

_No arguments._

**Returns:** `vector`

| `sleep` | `0.0` |
