# `ll.GetDayLength`

```lua
ll.GetDayLength() -> number
```

Returns the number of seconds that make up the day cycle for the current parcel’s environment, as an integer.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `time` |
