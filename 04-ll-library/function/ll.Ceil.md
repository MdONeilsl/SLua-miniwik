# `ll.Ceil`

```lua
ll.Ceil(val: number) -> number
```

Rounds the given floating-point value upward to the nearest integer, always moving toward positive infinity, which means it returns the smallest integer that is not less than the input value.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Number to round up. |

**Returns:** `number`

## Deprecated

- **reason:** Fastcall.
