# `ll.SetTimerEvent`

```lua
ll.SetTimerEvent(sec: number) -> ()
```

Configures a recurring timer that fires a timer event at regular intervals, each lasting sec seconds; setting sec to 0.0 disables any further timer events.


## Arguments

| Name | Type | Description |
|---|---|---|
| `sec` | `number` | Interval in seconds between timer events (0.0 to disable). |

**Returns:** `()`

| Field | Value |
|---|---|

| `sleep` | `0.0` |
