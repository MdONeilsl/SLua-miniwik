# `ll.Wind`

```lua
ll.Wind(offset: vector) -> vector
```

Returns the wind velocity vector at the prim’s position, adjusted by the specified local offset vector.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset relative to the prim's position, expressed in local coordinates. |

**Returns:** `vector`
