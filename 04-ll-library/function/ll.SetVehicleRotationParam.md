# `ll.SetVehicleRotationParam`

```lua
ll.SetVehicleRotationParam(param: number, rot: quaternion) -> ()
```

Assigns the given quaternion value to the vehicle rotation parameter specified by param.

## Arguments

| Name | Type | Description |
|---|---|---|
| `param` | `number` | VEHICLE_* rotation parameter constant to set. |
| `rot` | `quaternion` | Rotation value to set. |

**Returns:** `()`
