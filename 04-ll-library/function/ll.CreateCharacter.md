# `ll.CreateCharacter`

```lua
ll.CreateCharacter(options: list) -> ()
```

Transforms the current linkset into a pathfinding character entity, which is necessary for utilizing pathfinding functions, based on the provided configuration options.


## Arguments

| Name | Type | Description |
|---|---|---|
| `options` | `list` | A list of key-value pairs specifying the character's configuration options. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `pathfinding` |
