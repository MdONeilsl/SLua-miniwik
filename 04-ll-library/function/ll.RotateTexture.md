# `ll.RotateTexture`

```lua
ll.RotateTexture(angle: number, face: number) -> ()
```

Applies a rotational transformation to the specified face's texture, measured in radians. When the face parameter is set to ALL_SIDES, the rotation affects all faces uniformly.


## Arguments

| Name | Type | Description |
|---|---|---|
| `angle` | number | Rotation angle expressed in radians. |
| `face` | number | Face number or ALL_SIDES. |

**Returns:** `()`
