# `ll.GetSunDirection`

```lua
ll.GetSunDirection() -> vector
```

Returns a normalized vector indicating the current sun direction for the parcel, adjusted for altitude. If no custom parcel environment is active, it defaults to the region’s sun direction.


## Arguments

_No arguments._

**Returns:** `vector`

| `sleep` | `0.0` |
