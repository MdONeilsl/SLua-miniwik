# `ll.DetectedTouchFace`

```lua
ll.DetectedTouchFace(index: number) -> number
```

Given an event index, this function returns the integer identifier of the face that was touched by the avatar during that specific touch event.


## Arguments

| Name | Type | Description |
|---|---|---|
| index | number | Index of the detection information. |

**Returns:** `number`
