# `ll.List2Rot`

```lua
ll.List2Rot(src: list, index: number) -> quaternion
```

Retrieves the rotation value located at the specified index within the given list. If the index is invalid or the value cannot be converted to a rotation, it returns ZERO_ROTATION.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | Source list containing the element of interest. |
| `index` | `number` | Zero-based index of the entry. |

**Returns:** `quaternion`
