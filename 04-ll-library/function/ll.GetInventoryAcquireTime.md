# `ll.GetInventoryAcquireTime`

```lua
ll.GetInventoryAcquireTime(item: string) -> string
```

This function provides the UTC timestamp indicating when the specified item was added to the prim's inventory, formatted as "YYYY-MM-DDThh:mm:ssZ".

## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `string` | Name of the item in the prim's inventory. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim_inventory` |
