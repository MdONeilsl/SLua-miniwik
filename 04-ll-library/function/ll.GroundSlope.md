# `ll.GroundSlope`

```lua
ll.GroundSlope(offset: vector) -> vector
```

Returns a vector indicating the slope of the ground directly beneath the prim, adjusted by the specified local offset vector.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset relative to the prim's position, expressed in local coordinates. |

**Returns:** `vector`
