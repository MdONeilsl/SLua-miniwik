# `ll.GetObjectPermMask`

```lua
ll.GetObjectPermMask(group: number) -> number
```

Returns the permission flags associated with the script's object for the given group.


## Arguments

| Name | Type | Description |
|---|---|---|
| `group` | `number` | MASK_* group (e.g., MASK_BASE, MASK_OWNER, MASK_GROUP, MASK_EVERYONE, or MASK_NEXT) to get. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `asset_permissions`, `linkset` |
