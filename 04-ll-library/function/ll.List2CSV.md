# `ll.List2CSV`

```lua
ll.List2CSV(src: list) -> string
```

Converts the given list into a comma-separated string, preserving the elements in their original sequence.


## Arguments

| Name | Type | Description |
|---|---|---|
| src | `list` | Source list to convert. |

**Returns:** `string`
