# `ll.LinkStopSound`

```lua
ll.LinkStopSound(link: number) -> ()
```

Halts the playback of any sound currently attached and playing on the specified prim link.


## Arguments

| Name | Type | Description |
|---|---|---|
| `link` | `number` | Link number (1 for root, >1 for children) or a LINK_* flag. |

**Returns:** `()`

| `sleep` | `0.0` |
