# `ll.List2Float`

```lua
ll.List2Float(src: list, index: number) -> number
```

Retrieves the floating-point value located at the specified index within the given list. If the index is invalid or the element cannot be converted to a float, it returns 0.0.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | Source list containing the element of interest. |
| `index` | `number` | Zero-based index of the entry. |

**Returns:** `number`

## Deprecated

- **reason:** Use '[]' and 'tonumber' instead.
