# `ll.GetLocalPos`

```lua
ll.GetLocalPos() -> vector
```

Returns a vector indicating the position relative to the root prim; when invoked from the root prim itself, it yields the global region position or the position relative to the attachment point if the prim is attached.


## Arguments

_No arguments._

**Returns:** `vector`
