# `ll.SetVehicleFlags`

```lua
ll.SetVehicleFlags(flags: number) -> ()
```

Activates the vehicle flags defined by the provided Flags bitmask.


## Arguments

| Name | Type | Description |
|---|---|---|
| flags | number | A bitwise mask of VEHICLE_FLAG_* constants to enable. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| energy | `10.0` |
| sleep | `0.0` |
| categories | `vehicles` |
