# `ll.GetAgentLanguage`

```lua
ll.GetAgentLanguage(avatar: uuid) -> string
```

Returns the preferred interface language code as a string, as configured by the specified avatar.


## Arguments

| Name | Type | Description |
|---|---|---|
| `avatar` | `uuid` | UUID of the avatar in the same region. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar` |
