# `ll.GetRegionTimeDilation`

```lua
ll.GetRegionTimeDilation() -> number
```

This function returns a floating-point value indicating the current physics time dilation factor for the region, where 0.0 signifies maximum time dilation (slow motion) and 1.0 represents no time dilation (real-world speed).

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region` |
