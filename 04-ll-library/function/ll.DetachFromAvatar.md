# `ll.DetachFromAvatar`

```lua
ll.DetachFromAvatar() -> ()
```

Removes the script's object from attachment to the avatar. This operation demands the PERMISSION_ATTACH runtime permission (which is automatically provided to objects currently attached to avatars). The object is fully removed from the region and does not land on the ground.


## Arguments

_No arguments._

**Returns:** `()`
