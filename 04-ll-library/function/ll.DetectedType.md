# `ll.DetectedType`

```lua
ll.DetectedType(number: number) -> number
```

This function returns an integer bitfield indicating the detection type (AGENT, ACTIVE, PASSIVE, or SCRIPTED) for the specified detected object or avatar, identified by the given index. It returns 0 if the provided index is invalid.


## Arguments

| Name | Type | Description |
|---|---|---|
| `number` | number | Index of the detection information. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `detected` |
