# `ll.Cos`

```lua
ll.Cos(theta: number) -> number
```

Computes the cosine of the given angle, theta, which must be provided in radians.

## Arguments

| Name | Type | Description |
|---|---|---|
| `theta` | number | Angle in radians. |

**Returns:** `number`

## Deprecated

- **use:** math.cos
- **reason:** Double precision; fastcall.
