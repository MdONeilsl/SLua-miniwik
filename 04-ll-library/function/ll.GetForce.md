# `ll.GetForce`

```lua
ll.GetForce() -> vector
```

This function returns a vector that indicates the constant force being exerted on the object, provided the object has physical properties.

## Arguments

_No arguments._

**Returns:** `vector`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `physics` |
