# `ll.SameGroup`

```lua
ll.SameGroup(uuid: uuid) -> boolean
```

Returns true if the specified uuid refers to an agent or object that resides in the same region (simulator) and belongs to the same active group as the prim hosting the script; otherwise returns false.


## Arguments

| Name | Type | Description |
|---|---|---|
| `uuid` | `uuid` | UUID of the group, avatar, or prim to check. |

**Returns:** `boolean`
