# `ll.UpdateCharacter`

```lua
ll.UpdateCharacter(options: list) -> ()
```

Modifies the configuration of a pathfinding character based on the parameters provided in the options list, which uses the same constants as ll.CreateCharacter.


## Arguments

| Name | Type | Description |
|---|---|---|
| `options` | `list` | A list of key-value pairs specifying the character's new configuration options (takes same constants as ll.CreateCharacter). |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `pathfinding` |
