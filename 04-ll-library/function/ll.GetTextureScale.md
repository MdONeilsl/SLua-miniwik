# `ll.GetTextureScale`

```lua
ll.GetTextureScale(face: number) -> vector
```

For the specified face, this function returns a vector where the X and Y components represent the texture scaling factors, with the Z component being irrelevant.


## Arguments

| Name | Type | Description |
|---|---|---|
| `face` | `number` | Face number or ALL_SIDES. |

**Returns:** `vector`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `prim_appearance` |
