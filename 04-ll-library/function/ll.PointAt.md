# `ll.PointAt`

```lua
ll.PointAt(pos: vector) -> ()
```

Makes the avatar controlling the object orient itself to face the specified position vector.

## Arguments

| Name | Type | Description |
|---|---|---|
| `pos` | `vector` | Position vector to point at. |

**Returns:** `()`
