# `ll.GetRegionSunRotation`

```lua
ll.GetRegionSunRotation() -> quaternion
```

This function returns a rotation value that defines how the sun is oriented within the region, factoring in any altitude tracking adjustments.

## Arguments

_No arguments._

**Returns:** `quaternion`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region`, `region_appearance` |
