# `ll.ReleaseURL`

```lua
ll.ReleaseURL(url: string) -> ()
```

This function deallocates a URL that was previously requested using ll.RequestURL, making it invalid for further use.


## Arguments

| Name | Type | Description |
|---|---|---|
| `url` | `string` | URL string to release. |

**Returns:** `()`
