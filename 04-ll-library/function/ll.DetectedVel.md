# `ll.DetectedVel`

```lua
ll.DetectedVel(number: number) -> vector
```

For the given detection index, this function returns the velocity vector of the corresponding detected object or avatar; if the index is invalid, it returns the zero vector <0.0, 0.0, 0.0>.


## Arguments

| Name | Type | Description |
|---|---|---|
| `number` | `number` | Index of the detection information. |

**Returns:** `vector`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `detected` |
