# `ll.SHA256String`

```lua
ll.SHA256String(src: string) -> string
```

Computes and returns the SHA-256 cryptographic hash of the input string, formatted as a 64-character hexadecimal string.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `string` | Source string to hash. |

**Returns:** `string`
