# `ll.RemoveInventory`

```lua
ll.RemoveInventory(item: string) -> ()
```

Deletes the specified item from the prim's inventory in a permanent manner.


## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `string` | Name of the item in the prim's inventory to remove. |

**Returns:** `()`
