# `ll.SetSitText`

```lua
ll.SetSitText(text: string) -> ()
```

When the viewer right-clicks, the context menu will show the provided string instead of the default 'Sit' or 'Sit Here'.

## Arguments

| Name | Type | Description |
|---|---|---|
| `text` | `string` | Context menu text to display. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `sit`, `user_interface` |
