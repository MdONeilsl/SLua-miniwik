# `ll.Tan`

```lua
ll.Tan(theta: number) -> number
```

Computes the tangent of the given angle, theta, which must be specified in radians.


## Arguments

| Name | Type | Description |
|---|---|---|
| `theta` | `number` | Angle in radians. |

**Returns:** `number`

## Deprecated

- **use:** math.tan
- **reason:** Double precision; fastcall.
