# `ll.GetStatus`

```lua
ll.GetStatus(status: number) -> boolean
```

Returns an integer value that indicates whether the given status flag is currently active on the object.


## Arguments

| Name | Type | Description |
|---|---|---|
| `status` | `number` | Single STATUS_* flag to check. |

**Returns:** `boolean`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset`, `physics` |
