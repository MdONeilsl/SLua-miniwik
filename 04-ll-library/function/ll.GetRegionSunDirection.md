# `ll.GetRegionSunDirection`

```lua
ll.GetRegionSunDirection() -> vector
```

This function provides a normalized vector indicating the current direction of the sun within the region, adjusted for solar altitude.

## Arguments

_No arguments._

**Returns:** `vector`
