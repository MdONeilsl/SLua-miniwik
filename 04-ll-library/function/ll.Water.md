# `ll.Water`

```lua
ll.Water(offset: vector) -> number
```

Returns the water height at the point directly beneath the prim, adjusted by the specified local vector offset.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset relative to the prim's position, expressed in local coordinates. |

**Returns:** `number`
