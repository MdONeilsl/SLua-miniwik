# `ll.DetectedRezzer`

```lua
ll.DetectedRezzer(number: number) -> uuid
```

Given a detection index, this function returns the unique identifier (UUID) of the object or avatar that initiated the rez of the corresponding detected item.


## Arguments

| Name | Type | Description |
|---|---|---|
| `number` | `number` | Index of the detection information. |

**Returns:** `uuid`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `detected` |
