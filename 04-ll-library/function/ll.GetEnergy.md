# `ll.GetEnergy`

```lua
ll.GetEnergy() -> number
```

This function returns a floating-point value indicating the current physics energy level of the object, expressed as a proportion (ranging from 0.0 to 1.0) of its total energy capacity.

## Arguments

_No arguments._

**Returns:** `number`
