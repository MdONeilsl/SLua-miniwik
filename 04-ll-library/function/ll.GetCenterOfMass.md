# `ll.GetCenterOfMass`

```lua
ll.GetCenterOfMass() -> vector
```

Returns the center of mass as a vector in region coordinates. When invoked from a child prim, it returns that prim’s own center of mass; when called from the root prim, it returns the combined center of mass of the entire linkset.


## Arguments

_No arguments._

**Returns:** `vector`
