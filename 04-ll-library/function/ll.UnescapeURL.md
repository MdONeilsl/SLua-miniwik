# `ll.UnescapeURL`

```lua
ll.UnescapeURL(url: string) -> string
```

Converts the given URL string into its unescaped form by substituting '%20' with spaces and properly decoding any raw UTF-8 sequences.


## Arguments

| Name | Type | Description |
|---|---|---|
| `url` | `string` | Escaped URL string to decode. |

**Returns:** `string`
