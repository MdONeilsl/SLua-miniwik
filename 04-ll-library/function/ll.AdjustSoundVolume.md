# `ll.AdjustSoundVolume`

```lua
ll.AdjustSoundVolume(volume: number) -> ()
```

Changes the volume of the sound currently playing from an attached source, with no impact on sounds initiated via ll.TriggerSound.


## Arguments

| Name | Type | Description |
|---|---|---|
| `volume` | `number` | Volume level to set, between 0.0 (silent) and 1.0 (loud). |

**Returns:** `()`
