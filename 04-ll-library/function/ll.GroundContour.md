# `ll.GroundContour`

```lua
ll.GroundContour(offset: vector) -> vector
```

This function returns a vector indicating the ground contour direction—where elevation remains constant—located directly beneath the prim, adjusted by the specified offset vector.

## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset relative to the prim's position, expressed in local coordinates. |

**Returns:** `vector`
