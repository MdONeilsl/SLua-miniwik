# `ll.InstantMessage`

```lua
ll.InstantMessage(agent: uuid, msg: string) -> ()
```

Transmits the specified message text to the target agent, identified by their unique key.


## Arguments

| Name | Type | Description |
|---|---|---|
| `agent` | `uuid` | UUID of the destination agent. |
| `msg` | `string` | Text message string to send. |

**Returns:** `()`
