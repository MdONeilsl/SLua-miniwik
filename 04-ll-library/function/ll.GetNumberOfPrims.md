# `ll.GetNumberOfPrims`

```lua
ll.GetNumberOfPrims() -> number
```

Returns the count of prims and seated avatars within the linkset that contains the script, as an integer.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset` |
