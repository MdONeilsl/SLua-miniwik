# `ll.GetListLength`

```lua
ll.GetListLength(src: list) -> number
```

Returns the count of elements contained within the specified list as an integer.

## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | List to measure. |

**Returns:** `number`
