# `ll.ComputeHash`

```lua
ll.ComputeHash(message: string, algorithm: string) -> string
```

Generates a hexadecimal representation of the cryptographic hash for the given message, computed using the specified algorithm.


## Arguments

| Name | Type | Description |
|---|---|---|
| `message` | `string` | Message string to be hashed. |
| `algorithm` | `string` | Cryptographic digest algorithm to use (e.g., md5, sha1, sha224, sha256, sha384, or sha512). |

**Returns:** `string`
