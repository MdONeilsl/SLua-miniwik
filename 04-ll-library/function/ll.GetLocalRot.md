# `ll.GetLocalRot`

```lua
ll.GetLocalRot() -> quaternion
```

This function returns the local rotational orientation of a child prim with respect to its parent prim, or the global rotation of the object if invoked from the root prim.


## Arguments

_No arguments._

**Returns:** `quaternion`
