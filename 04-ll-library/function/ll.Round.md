# `ll.Round`

```lua
ll.Round(val: number) -> number
```

Rounds the given floating-point value to the nearest integer, with ties rounded toward positive infinity.


## Arguments

| Name | Type | Description |
|---|---|---|
| val | number | Number to round. |

**Returns:** `number`
