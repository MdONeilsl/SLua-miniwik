# `ll.ToLower`

```lua
ll.ToLower(src: string) -> string
```

Converts the input string to lowercase, preserving all Unicode characters beyond just ASCII.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `string` | Source string to convert. |

**Returns:** `string`
