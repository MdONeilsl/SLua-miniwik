# `ll.ResetOtherScript`

```lua
ll.ResetOtherScript(script: string) -> ()
```

Restores the specified script by its name within the prim's inventory.

## Arguments

| Name | Type | Description |
|---|---|---|
| `script` | `string` | Name of the target script in the prim's inventory. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim_inventory`, `script` |
