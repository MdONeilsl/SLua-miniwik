# `ll.AvatarOnSitTarget`

```lua
ll.AvatarOnSitTarget() -> uuid
```

This function returns the unique identifier (UUID) of the avatar currently seated on the prim’s sit target, as defined by ll.SitTarget; it returns NULL_KEY if no avatar is seated or if the prim does not have a defined sit target.

## Arguments

_No arguments._

**Returns:** `uuid`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `prim`, `sit` |
