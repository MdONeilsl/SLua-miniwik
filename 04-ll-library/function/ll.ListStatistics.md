# `ll.ListStatistics`

```lua
ll.ListStatistics(operation: number, src: list) -> number
```

Computes and returns the numerical outcome of the specified statistical aggregate operation (represented by a LIST_STAT_* constant) applied to the provided numeric list src.

## Arguments

| Name | Type | Description |
|---|---|---|
| `operation` | `number` | LIST_STAT_* constant of the statistical operation to perform. |
| `src` | `list` | List of numbers to analyze. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `list`, `math` |
