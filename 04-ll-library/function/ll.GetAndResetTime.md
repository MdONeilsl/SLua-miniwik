# `ll.GetAndResetTime`

```lua
ll.GetAndResetTime() -> number
```

This function retrieves the current accumulated script runtime in seconds as a floating-point value and immediately resets the timer to zero.


## Arguments

_No arguments._

**Returns:** `number`

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `script` |
