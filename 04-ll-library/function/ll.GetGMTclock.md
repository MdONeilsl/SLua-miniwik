# `ll.GetGMTclock`

```lua
ll.GetGMTclock() -> number
```

Returns the current time as a floating-point value, measured in seconds elapsed since midnight GMT, with fractional seconds truncated to whole numbers.


## Arguments

_No arguments._

**Returns:** `number`

| `sleep` | `0.0` |
