# `ll.GetRegionMoonDirection`

```lua
ll.GetRegionMoonDirection() -> vector
```

Returns a normalized vector indicating the present orientation of the moon within the region, adjusted for its altitude.


## Arguments

_No arguments._

**Returns:** `vector`
