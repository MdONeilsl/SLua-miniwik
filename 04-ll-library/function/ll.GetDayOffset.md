# `ll.GetDayOffset`

```lua
ll.GetDayOffset() -> number
```

Returns an integer value indicating the time offset in seconds that is applied to determine the current environmental time on this parcel.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `time` |
