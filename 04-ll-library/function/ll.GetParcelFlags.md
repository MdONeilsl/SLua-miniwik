# `ll.GetParcelFlags`

```lua
ll.GetParcelFlags(pos: vector) -> number
```

Returns an integer representing a bitmask of parcel flags (PARCEL_FLAG_*) corresponding to the parcel located at the specified position pos.


## Arguments

| Name | Type | Description |
|---|---|---|
| `pos` | `vector` | Position vector in region coordinates (the Z component is ignored). |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
energy | 10.0 |
sleep | 0.0 |
categories | parcel |
