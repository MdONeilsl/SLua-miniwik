# `ll.IsFriend`

```lua
ll.IsFriend(agent_id: uuid) -> boolean
```

Returns 1 if the specified agent is a friend of the script's owner, and 0 otherwise.

## Arguments

| Name | Type | Description |
|---|---|---|
| `agent_id` | `uuid` | UUID of the agent to check. |

**Returns:** `boolean`
