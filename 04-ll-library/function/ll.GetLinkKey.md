# `ll.GetLinkKey`

```lua
ll.GetLinkKey(link: number) -> uuid
```

Given a link identifier, this function retrieves the unique identifier (UUID) of the associated prim or avatar.

## Arguments

| Name | Type | Description |
|---|---|---|
| `link` | `number` | Link number (1 for root, >1 for children) or a LINK_* flag. |

**Returns:** `uuid`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset`, `uuid` |
