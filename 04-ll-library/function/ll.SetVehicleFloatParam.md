# `ll.SetVehicleFloatParam`

```lua
ll.SetVehicleFloatParam(param: number, value: number) -> ()
```

Assigns the given float value to the specified vehicle parameter, identified by the integer constant.


## Arguments

| Name | Type | Description |
|---|---|---|
| `param` | `number` | VEHICLE_* float parameter constant to set. |
| `value` | `number` | Float value to set. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `vehicles` |
