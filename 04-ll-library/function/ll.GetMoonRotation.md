# `ll.GetMoonRotation`

```lua
ll.GetMoonRotation() -> quaternion
```

This function returns a rotation value that defines how the moon is oriented on the current parcel and its altitude track. If no custom parcel environment is active, it defaults to the region’s predefined moon rotation.


## Arguments

_No arguments._

**Returns:** `quaternion`
