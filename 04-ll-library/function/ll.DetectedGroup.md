# `ll.DetectedGroup`

```lua
ll.DetectedGroup(number: number) -> boolean
```

Returns true if the object or avatar identified by the given number belongs to the same active group as the prim hosting the script; otherwise returns false, when the group is inactive or the entity is not part of the group.

## Arguments

| Name | Type | Description |
|---|---|---|
| `number` | number | Index of the detection information. |

**Returns:** `boolean`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `detected` |
