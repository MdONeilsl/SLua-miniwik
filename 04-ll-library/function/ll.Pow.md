# `ll.Pow`

```lua
ll.Pow(base: number, exponent: number) -> number
```

Raises the base to the power of the exponent. If the result is imaginary, it returns NaN.


## Arguments

| Name | Type | Description |
|---|---|---|
| `base` | `number` | Base number. |
| `exponent` | `number` | Exponent number. |

**Returns:** `number`
