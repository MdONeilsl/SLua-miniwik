# `ll.GetMinScaleFactor`

```lua
ll.GetMinScaleFactor() -> number
```

Returns the smallest scale factor that can be used with ll.ScaleByFactor without exceeding the object's size constraints.

## Arguments

_No arguments._

**Returns:** `number`
