# `ll.GetMemoryLimit`

```lua
ll.GetMemoryLimit() -> number
```

This function returns an integer value indicating the maximum amount of memory (measured in bytes) that the script is permitted to use.

## Arguments

_No arguments._

**Returns:** `number`
