# `ll.GetRegionFPS`

```lua
ll.GetRegionFPS() -> number
```

Returns the average frames per second (FPS) that the region simulator is running at, as a floating-point number.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region` |
