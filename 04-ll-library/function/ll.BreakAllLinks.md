# `ll.BreakAllLinks`

```lua
ll.BreakAllLinks() -> ()
```

This function severs all linked primitives within the current linkset. It necessitates the PERMISSION_CHANGE_LINKS runtime permission, which must be explicitly requested and approved by the script’s owner.

## Arguments

_No arguments._

**Returns:** `()`
