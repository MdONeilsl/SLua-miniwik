# `ll.ToUpper`

```lua
ll.ToUpper(src: string) -> string
```

Converts the input string to uppercase, supporting all Unicode characters beyond just ASCII.


## Arguments

| Name | Type | Description |
|---|---|---|
| src | string | Source string to convert. |

**Returns:** `string`
