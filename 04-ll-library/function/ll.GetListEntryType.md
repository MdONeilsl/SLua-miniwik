# `ll.GetListEntryType`

```lua
ll.GetListEntryType(src: list, index: number) -> number
```

Returns an integer indicating the type (TYPE_*) of the element located at the specified index within the given list src.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | Source list containing the element of interest. |
| `index` | `number` | Zero-based index of the entry. |

**Returns:** `number`
