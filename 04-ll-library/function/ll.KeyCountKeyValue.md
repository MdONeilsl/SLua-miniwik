# `ll.KeyCountKeyValue`

```lua
ll.KeyCountKeyValue() -> uuid
```

Initiates an asynchronous operation to retrieve the total number of keys stored in the experience data store, and returns a handle used to track the dataserver event.


## Arguments

_No arguments._

**Returns:** `uuid`
