# `ll.SetVehicleVectorParam`

```lua
ll.SetVehicleVectorParam(param: number, vec: vector) -> ()
```

Assigns the given vector value to the specified vehicle vector parameter.


## Arguments

| Name | Type | Description |
|---|---|---|
| `param` | `number` | VEHICLE_* vector parameter constant to set. |
| `vec` | `vector` | Vector value to set. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `vehicles` |
