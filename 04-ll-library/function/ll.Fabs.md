# `ll.Fabs`

```lua
ll.Fabs(val: number) -> number
```

Returns the non-negative value of the given floating-point number.


## Arguments

| Name | Type | Description |
|---|---|---|
| val | number | Number to convert. |

**Returns:** `number`

## Deprecated

- **use:** math.abs
- **reason:** Double precision; fastcall.
