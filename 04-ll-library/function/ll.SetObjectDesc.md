# `ll.SetObjectDesc`

```lua
ll.SetObjectDesc(description: string) -> ()
```

Assigns the provided string as the description for the prim that contains the script, with a maximum length of 127 characters.


## Arguments

| Name | Type | Description |
|---|---|---|
| `description` | `string` | New description string (up to 127 characters). |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `prim_properties` |
