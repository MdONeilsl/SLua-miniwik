# `ll.ParcelMediaCommandList`

```lua
ll.ParcelMediaCommandList(commandList: list) -> ()
```

Manages the playback of multimedia content such as movies on a parcel or for an agent, by applying the PARCEL_MEDIA_COMMAND_* values defined within the provided commandList.


## Arguments

| Name | Type | Description |
|---|---|---|
| `commandList` | `list` | A list containing integer PARCEL_MEDIA_COMMAND_* flags and their corresponding parameters. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `2.0` |
| `categories` | `media`, `parcel`, `parcel_media` |
