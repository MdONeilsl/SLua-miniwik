# `ll.GetPermissions`

```lua
ll.GetPermissions() -> number
```

This function returns an integer bitmask that indicates the permissions (PERMISSION_*) currently active for the script.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `permissions` |
