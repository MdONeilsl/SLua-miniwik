# `ll.SetText`

```lua
ll.SetText(text: string, color: vector, alpha: number) -> ()
```

Shows a text label floating above the prim, using the provided RGB color vector and alpha transparency level.


## Arguments

| Name | Type | Description |
|---|---|---|
| `text` | `string` | Floating text string to display. |
| `color` | `vector` | Color vector in RGB <R, G, B> (values from 0.0 to 1.0). |
| `alpha` | `number` | Transparency value to set, from 0.0 (clear) to 1.0 (solid). |

**Returns:** `()`
