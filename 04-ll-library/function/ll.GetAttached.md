# `ll.GetAttached`

```lua
ll.GetAttached() -> number
```

Returns the integer value representing the attachment point (a valid ATTACH_* constant) to which the object is currently bound, or 0 if the object is not attached or is in the process of detaching.


## Arguments

_No arguments._

**Returns:** `number`
