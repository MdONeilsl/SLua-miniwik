# `ll.DetectedName`

```lua
ll.DetectedName(item: number) -> string
```

Given an integer index, this function returns a string that identifies the detected object or avatar. If the index is invalid, it returns an empty string.

## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `number` | Index of the detection information. |

**Returns:** `string`
