# `ll.GetLinkSitFlags`

```lua
ll.GetLinkSitFlags(link: number) -> number
```

Returns an integer value indicating the currently active sit flags applied to the prim referenced by the specified link.


## Arguments

| Name | Type | Description |
|---|---|---|
| `link` | `number` | Link number (1 for root, >1 for children) or a LINK_* flag. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset`, `sit` |
