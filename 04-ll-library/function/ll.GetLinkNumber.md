# `ll.GetLinkNumber`

```lua
ll.GetLinkNumber() -> number
```

This function returns an integer representing the link number of the primitive that hosts the script, with 0 indicating no link, 1 for the root prim, and 2 or higher for child prims.


## Arguments

_No arguments._

**Returns:** `number`
