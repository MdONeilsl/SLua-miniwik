# `ll.GetSimStats`

```lua
ll.GetSimStats(stat_type: number) -> number
```

Returns a floating-point value representing the specified region statistic, determined by the stat_type parameter.


## Arguments

| Name | Type | Description |
|---|---|---|
| stat_type | number | SIM_STAT_* flag of the statistic to retrieve. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| energy | `10.0` |
| sleep | `0.0` |
| categories | `region` |
