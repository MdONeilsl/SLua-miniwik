# `ll.SetPrimitiveParams`

```lua
ll.SetPrimitiveParams(rules: list) -> ()
```

This function is deprecated; use ll.SetLinkPrimitiveParamsFast instead. It configures the prim’s properties based on the provided rules.

## Arguments

| Name | Type | Description |
|---|---|---|
| `rules` | `list` | A list of PRIM_* rules and data to apply. |

**Returns:** `()`

## Deprecated
