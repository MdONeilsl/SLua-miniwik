# `ll.Rot2Axis`

```lua
ll.Rot2Axis(rot: quaternion) -> vector
```

Given a rotation `q`, this function extracts and returns the unit vector representing the axis of rotation.

## Arguments

| Name | Type | Description |
|---|---|---|
| `rot` | `quaternion` | Rotation to evaluate. |

**Returns:** `vector`
