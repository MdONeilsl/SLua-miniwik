# `ll.LinksetDataRead`

```lua
ll.LinksetDataRead(name: string) -> string
```

Retrieves the value associated with an unprotected key in the linkset datastore. If the key does not exist or is protected, it returns an empty string.


## Arguments

| Name | Type | Description |
|---|---|---|
| `name` | `string` | — |

**Returns:** `string`
