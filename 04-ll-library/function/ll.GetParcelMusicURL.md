# `ll.GetParcelMusicURL`

```lua
ll.GetParcelMusicURL() -> string
```

This function returns the URL for the parcel's streaming audio content. The owner of the object must also be the parcel's land owner or belong to the same group that owns the land.

## Arguments

_No arguments._

**Returns:** `string`
