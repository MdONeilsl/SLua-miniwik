# `ll.GetRenderMaterial`

```lua
ll.GetRenderMaterial(face: number) -> string
```

Returns a string that identifies the render material applied to the specified face, which will be the inventory name if the material is stored in the prim’s inventory, or its key UUID if it is not.

## Arguments

| Name | Type | Description |
|---|---|---|
| `face` | `number` | Face number or ALL_SIDES. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `prim`, `prim_appearance` |
