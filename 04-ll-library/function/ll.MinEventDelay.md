# `ll.MinEventDelay`

```lua
ll.MinEventDelay(delay: number) -> ()
```

Defines the shortest interval allowed between consecutive event processing calls, with specific minimum and default values depending on the event type.

## Arguments

| Name | Type | Description |
|---|---|---|
| `delay` | `number` | Minimum delay duration in seconds. |

**Returns:** `()`
