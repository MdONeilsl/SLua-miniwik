# `ll.GetTimestamp`

```lua
ll.GetTimestamp() -> string
```

Returns a string representation of the current UTC date and time, formatted according to the ISO 8601 standard as 'YYYY-MM-DDThh:mm:ss.ff..fZ'.

## Arguments

_No arguments._

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `time` |
