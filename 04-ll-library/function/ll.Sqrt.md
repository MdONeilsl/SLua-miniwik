# `ll.Sqrt`

```lua
ll.Sqrt(val: number) -> number
```

Computes the square root of the given value; returns NaN if the input is negative.


## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | number | Positive float value (must be >= 0.0). |

**Returns:** `number`

## Deprecated

- **use:** math.sqrt
- **reason:** Double precision; fastcall.
