# `ll.StopMoveToTarget`

```lua
ll.StopMoveToTarget() -> ()
```

Halts the critically damped translational movement of the object toward a specified target, effectively canceling any ongoing ll.MoveToTarget operation. To stop rotational tracking, use ll.StopLookAt instead.


## Arguments

_No arguments._

**Returns:** `()`

| `sleep` | `0.0` |
