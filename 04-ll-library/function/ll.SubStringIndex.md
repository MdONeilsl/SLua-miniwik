# `ll.SubStringIndex`

```lua
ll.SubStringIndex(source: string, pattern: string) -> number?
```

Finds the first occurrence of the specified substring within the given string and returns its codepoint position; returns -1 if the pattern is not found. Does not support regular expressions.


## Arguments

| Name | Type | Description |
|---|---|---|
| `source` | `string` | Source string to search within. |
| `pattern` | `string` | Substring pattern to search for. |

**Returns:** `number?`

|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
