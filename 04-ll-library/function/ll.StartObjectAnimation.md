# `ll.StartObjectAnimation`

```lua
ll.StartObjectAnimation(anim: string) -> ()
```

Initiates the given animation, either from the prim’s inventory or a built-in animation, on the rigged mesh object linked to the current script.

## Arguments

| Name | Type | Description |
|---|---|---|
| `anim` | `string` | Name of the animation in the prim's inventory, or the built-in animation name. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `object_animation` |
