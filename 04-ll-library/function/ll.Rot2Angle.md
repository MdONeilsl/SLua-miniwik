# `ll.Rot2Angle`

```lua
ll.Rot2Angle(rot: quaternion) -> number
```

Given a quaternion q, this function computes and returns the corresponding rotation angle in radians.

## Arguments

| Name | Type | Description |
|---|---|---|
| `rot` | `quaternion` | Rotation to evaluate. |

**Returns:** `number`
