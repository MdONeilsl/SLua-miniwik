# `ll.RemoveVehicleFlags`

```lua
ll.RemoveVehicleFlags(flags: number) -> ()
```

Sets the specified vehicle flags to FALSE by applying a bitwise mask, effectively disabling them.

## Arguments

| Name | Type | Description |
|---|---|---|
| `flags` | `number` | A bitwise mask of VEHICLE_FLAG_* constants to disable. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `physics`, `vehicles` |
