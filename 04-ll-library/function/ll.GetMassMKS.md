# `ll.GetMassMKS`

```lua
ll.GetMassMKS() -> number
```

Returns the object's mass as a floating-point value in kilograms, equivalent to ll.GetMass but expressed in metric (MKS) units.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset`, `physics` |
