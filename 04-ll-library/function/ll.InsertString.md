# `ll.InsertString`

```lua
ll.InsertString(dst: string, index: number, src: string) -> string
```

Produces a new string by inserting the contents of src into dst at the specified codepoint position.


## Arguments

| Name | Type | Description |
|---|---|---|
| `dst` | `string` | Target destination string. |
| `index` | `number` | Codepoint index where insertion starts. |
| `src` | `string` | Source string to insert. |

**Returns:** `string`
