# `ll.GetCameraPos`

```lua
ll.GetCameraPos() -> vector
```

Returns the current position of the camera in region coordinates for the agent that has granted PERMISSION_TRACK_CAMERA; if the necessary permissions are not held, it returns ZERO_VECTOR.

## Arguments

_No arguments._

**Returns:** `vector`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `camera`, `permissions` |
