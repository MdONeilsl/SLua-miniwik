# `ll.GetRegionDayLength`

```lua
ll.GetRegionDayLength() -> number
```

Returns the number of seconds that constitute a full day cycle across the entire region, as an integer.


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region`, `time` |
