# `ll.List2Vector`

```lua
ll.List2Vector(src: list, index: number) -> vector
```

Retrieves the vector located at the specified index within the given list. If the index is invalid or the element cannot be converted to a vector, it returns ZERO_VECTOR.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | Source list containing the element of interest. |
| `index` | `number` | Zero-based index of the entry. |

**Returns:** `vector`
