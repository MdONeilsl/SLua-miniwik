# `ll.StopLookAt`

```lua
ll.StopLookAt() -> ()
```

Halts the object from maintaining visual focus or directional orientation toward a specified target, effectively canceling any active ll.LookAt or ll.RotLookAt commands.


## Arguments

_No arguments._

**Returns:** `()`
