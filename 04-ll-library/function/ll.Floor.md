# `ll.Floor`

```lua
ll.Floor(val: number) -> number
```

Rounds the given value down to the nearest integer, always moving toward negative infinity, which means it returns the greatest integer that is less than or equal to the input value.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | Number to round down. |

**Returns:** `number`

- **reason:** Fastcall.
