# `ll.Hash`

```lua
ll.Hash(val: string) -> number
```

Computes and returns a 32-bit integer hash value for the given string `val`, with a result of 0 if the input string is empty.


## Arguments

| Name | Type | Description |
|---|---|---|
| val | `string` | String to hash. |

**Returns:** `number`
