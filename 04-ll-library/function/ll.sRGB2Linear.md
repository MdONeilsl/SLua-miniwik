# `llsRGB2Linear`

```lua
ll.sRGB2Linear(srgb: vector) -> vector
```

Converts a given color vector from the sRGB color space into its corresponding linear RGB representation.


## Arguments

| Name | Type | Description |
|---|---|---|
| `srgb` | `vector` | Color vector in the sRGB colorspace to convert. |

**Returns:** `vector`
