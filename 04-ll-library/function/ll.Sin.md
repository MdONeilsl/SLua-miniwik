# `ll.Sin`

```lua
ll.Sin(theta: number) -> number
```

Computes the sine of the given angle, theta, which must be specified in radians.

## Arguments

| Name | Type | Description |
|---|---|---|
| `theta` | `number` | Angle in radians. |

**Returns:** `number`

## Deprecated

- **use:** math.sin
- **reason:** Double precision; fastcall.
