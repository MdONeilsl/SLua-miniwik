# `ll.GetLandOwnerAt`

```lua
ll.GetLandOwnerAt(pos: vector) -> uuid
```

Returns the UUID of the landowner at the specified position vector, or NULL_KEY if the land is publicly owned.

## Arguments

| Name | Type | Description |
|---|---|---|
| `pos` | `vector` | Position vector in region coordinates. |

**Returns:** `uuid`
