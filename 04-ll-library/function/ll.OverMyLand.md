# `ll.OverMyLand`

```lua
ll.OverMyLand(id: uuid) -> boolean
```

Returns true if the specified avatar or object, identified by the key, is positioned on land that belongs to the script's owner; otherwise, returns false.


## Arguments

| Name | Type | Description |
|---|---|---|
| `id` | `uuid` | UUID of the group, avatar, or object to check. |

**Returns:** `boolean`
