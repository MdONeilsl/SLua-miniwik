# `ll.SetClickAction`

```lua
ll.SetClickAction(action: number) -> ()
```

When an avatar left-clicks the prim, this function assigns a specific CLICK_ACTION_* flag to define the resulting action.


## Arguments

| Name | Type | Description |
|---|---|---|
| `action` | `number` | CLICK_ACTION_* flag representing the action to apply. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `input`, `money`, `prim_properties`, `touch`, `user_interface` |
