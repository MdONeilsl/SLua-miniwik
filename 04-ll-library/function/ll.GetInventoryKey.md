# `ll.GetInventoryKey`

```lua
ll.GetInventoryKey(item: string) -> uuid
```

Given an item name from within a prim's inventory, this function retrieves the unique identifier (UUID) associated with that item.

## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `string` | Name of the item in the prim's inventory. |

**Returns:** `uuid`
