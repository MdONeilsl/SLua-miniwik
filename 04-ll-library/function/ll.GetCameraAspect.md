# `ll.GetCameraAspect`

```lua
ll.GetCameraAspect() -> number
```

Returns the current aspect ratio (width divided by height) of the camera belonging to the agent that has granted PERMISSION_TRACK_CAMERA. If the required permission is not held, the function returns 0.0.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `camera`, `permissions` |
