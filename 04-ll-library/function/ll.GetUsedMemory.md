# `ll.GetUsedMemory`

```lua
ll.GetUsedMemory() -> number
```

Returns an integer indicating the current memory usage in bytes for the script; non-Mono scripts consistently return 16,384 bytes.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `script` |
