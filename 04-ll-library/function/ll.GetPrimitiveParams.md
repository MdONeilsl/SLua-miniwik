# `ll.GetPrimitiveParams`

```lua
ll.GetPrimitiveParams(params: {number}) -> {any}
```

This function retrieves a list of attribute values for primitives based on the specified parameters.

## Arguments

| Name | Type | Description |
|---|---|---|
| `params` | `{number}` | A list of PRIM_* flags specifying the attributes to retrieve. |

**Returns:** `{any}`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.2` |
| `categories` | `prim`, `prim_appearance`, `prim_properties` |
