# `ll.GetRootRotation`

```lua
ll.GetRootRotation() -> quaternion
```

This function returns the rotational orientation, relative to the region, of the root primitive within the linkset that contains the current script.

## Arguments

_No arguments._

**Returns:** `quaternion`
