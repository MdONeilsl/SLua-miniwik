# `ll.SetObjectName`

```lua
ll.SetObjectName(name: string) -> ()
```

Assigns a new name to the prim that hosts the current script, using the specified string.

## Arguments

| Name | Type | Description |
|---|---|---|
| name | string | New name string.|

**Returns:** `()`
