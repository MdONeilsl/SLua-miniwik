# `ll.StringToBase64`

```lua
ll.StringToBase64(str: string) -> string
```

Converts the given string into its Base64-encoded form, treating the input as a sequence of UTF-8 bytes.


## Arguments

| Name | Type | Description |
|---|---|---|
| `str` | `string` | Source string to encode. |

**Returns:** `string`
