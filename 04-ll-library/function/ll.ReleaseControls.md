# `ll.ReleaseControls`

```lua
ll.ReleaseControls() -> ()
```

Ceases input capture (previously obtained through ll.TakeControls) from the avatar, clears any pending control events, and removes the PERMISSION_TAKE_CONTROLS permission.


## Arguments

_No arguments._

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `input`, `permissions` |
