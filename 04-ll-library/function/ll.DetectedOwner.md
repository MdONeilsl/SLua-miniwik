# `ll.DetectedOwner`

```lua
ll.DetectedOwner(number: number) -> uuid
```

Given a detection index, this function retrieves the UUID of the object's owner. If the index is invalid, it returns an invalid key.


## Arguments

| Name | Type | Description |
|---|---|---|
| `number` | `number` | Index of the detection information. |

**Returns:** `uuid`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `detected` |
