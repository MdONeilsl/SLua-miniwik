# `ll.GetInventoryDesc`

```lua
ll.GetInventoryDesc(item: string) -> string
```

This function retrieves the textual description associated with a given item from the prim's inventory.


## Arguments

| Name | Type | Description |
|---|---|---|
| `item` | `string` | Name of the item in the prim's inventory. |

**Returns:** `string`

| `sleep` | `0.0` |
