# `ll.SetCameraEyeOffset`

```lua
ll.SetCameraEyeOffset(offset: vector) -> ()
```

Configures the camera’s eye position offset relative to the prim, expressed in local coordinates, for avatars seated in the object.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset position vector in local coordinates relative to the prim. |

**Returns:** `()`
