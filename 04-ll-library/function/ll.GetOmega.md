# `ll.GetOmega`

```lua
ll.GetOmega() -> vector
```

This function returns a vector that indicates the object's rotational speed, measured in radians per second, reflecting its angular velocity due to physical rotation.


## Arguments

_No arguments._

**Returns:** `vector`

| `sleep` | `0.0` |
| `categories` | `movement`, `physics` |
