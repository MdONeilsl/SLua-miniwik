# `ll.GetSimulatorHostname`

```lua
ll.GetSimulatorHostname() -> string
```

Returns the hostname of the server machine executing the script, formatted as a string (for example, 'sim225.agni.lindenlab.com').


## Arguments

_No arguments._

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `10.0` |
| `categories` | `region` |
