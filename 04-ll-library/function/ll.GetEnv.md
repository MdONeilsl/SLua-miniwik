# `ll.GetEnv`

```lua
ll.GetEnv(name: string) -> string
```

Returns a string that corresponds to the specified regional data name; if the name is not recognized, an empty string is returned.


## Arguments

| Name | Type | Description |
|---|---|---|
| `name` | `string` | Name of the regional data to request (unrecognized strings return an empty string). |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region` |
