# `ll.StringLength`

```lua
ll.StringLength(str: string) -> number
```

Counts the number of Unicode code points present in the given string.

## Arguments

| Name | Type | Description |
|---|---|---|
| `str` | `string` | String to measure. |

**Returns:** `number`

## Deprecated

- **reason:** Use 'utf8.len' or '#' or 'string.len' instead.
