# `ll.List2Integer`

```lua
ll.List2Integer(src: list, index: number) -> number
```

Retrieves the integer value located at the specified index within the given list. If the index is invalid or the element cannot be converted to an integer, the function returns zero.


## Arguments

| Name | Type | Description |
|---|---|---|
| `src` | `list` | Source list containing the element of interest. |
| `index` | `number` | Zero-based index of the entry. |

**Returns:** `number`

## Deprecated

- **reason:** Use '[]', 'tonumber', and 'math.modf' instead.
