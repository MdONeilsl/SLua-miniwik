# `ll.GetMaxScaleFactor`

```lua
ll.GetMaxScaleFactor() -> number
```

Returns the maximum scale factor value that can be used with ll.ScaleByFactor without exceeding size or linkability constraints.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `linkset`, `prim_appearance` |
