# `ll.GetWallclock`

```lua
ll.GetWallclock() -> number
```

Returns a floating-point value indicating the number of seconds elapsed since midnight in Pacific Time (PST/PDT), matching the integer-second representation of Second Life Time (SLT).


## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `time` |
