# `ll.Log`

```lua
ll.Log(val: number) -> number
```

Computes the natural logarithm (base e) of the given value; for negative inputs, it yields 0.0.

## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | number | Number to compute the logarithm of. |

**Returns:** `number`

## Deprecated

- **use:** math.log
- **reason:** Double precision; fastcall.
