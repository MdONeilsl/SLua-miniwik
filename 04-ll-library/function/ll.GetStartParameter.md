# `ll.GetStartParameter`

```lua
ll.GetStartParameter() -> number
```

Returns an integer value corresponding to the start or rez parameter provided when the object was created, with a value of 0 if the object was rezzed by an agent.

## Arguments

_No arguments._

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `rez`, `script` |
