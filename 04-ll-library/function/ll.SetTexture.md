# `ll.SetTexture`

```lua
ll.SetTexture(texture: string | uuid, face: number) -> ()
```

Assigns a Blinn-Phong diffuse texture to the specified face of the prim.


## Arguments

| Name | Type | Description |
|---|---|---|
| `texture` | `string | uuid` | Name of a texture in the prim's inventory, or a UUID. |
| `face` | `number` | Face number or ALL_SIDES. |

**Returns:** `()`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.2` |
| `categories` | `prim`, `prim_appearance` |
