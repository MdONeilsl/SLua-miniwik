# `ll.Ord`

```lua
ll.Ord(val: string, index: number) -> number
```

Returns the Unicode code point integer corresponding to the character located at the specified index within the string val, with negative indices interpreted as counting from the end of the string.


## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `string` | Source string. |
| `index` | `number` | Codepoint index of the character to convert. Supports negative indexing. |

**Returns:** `number`
