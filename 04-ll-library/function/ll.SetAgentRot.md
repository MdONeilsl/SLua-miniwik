# `ll.SetAgentRot`

```lua
ll.SetAgentRot(rot: quaternion, flags: number) -> ()
```

Assigns the specified rotation to the avatar, with behavior modulated by the flags parameter.

## Arguments

| Name | Type | Description |
|---|---|---|
| `rot` | `quaternion` | Target rotation to turn the avatar to face. |
| `flags` | `number` | Flags to configure the rotation behavior. |

**Returns:** `()`
