# `ll.SetGroundTexture`

```lua
ll.SetGroundTexture(changes: list) -> number
```

Alters the terrain textures currently painted on the region using the provided changes. The script owner must possess estate management permissions. The function returns an integer indicating the operation's status.


## Arguments

| Name | Type | Description |
|---|---|---|
| `changes` | `list` | A list of terrain detail properties and values to change. |

**Returns:** `number`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `region` |
