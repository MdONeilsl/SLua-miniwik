# `ll.SetLocalRot`

```lua
ll.SetLocalRot(rot: quaternion) -> ()
```

Assigns a local rotation to a child prim, relative to its parent prim, using the specified rotation value.


## Arguments

| Name | Type | Description |
|---|---|---|
| `rot` | `quaternion` | Local rotation to set. |

**Returns:** `()`
