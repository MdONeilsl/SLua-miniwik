# `ll.Asin`

```lua
ll.Asin(val: number) -> number
```

Computes the inverse sine (arcsine) of the given value, returning the result in radians.


## Arguments

| Name | Type | Description |
|---|---|---|
| `val` | `number` | A number in the range [-1.0, 1.0]. |

**Returns:** `number`

## Deprecated

- **use:** math.asin
- **reason:** Double precision; fastcall.
