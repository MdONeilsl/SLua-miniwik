# `ll.RequestURL`

```lua
ll.RequestURL() -> uuid
```

Initiates an asynchronous HTTP request for the script, which will generate an http_request event upon completion. The function returns a unique key handle used to track the request.

## Arguments

_No arguments._

**Returns:** `uuid`
