# `ll.Cloud`

```lua
ll.Cloud(offset: vector) -> number
```

Returns a floating-point value indicating the density of clouds at the position of the prim, adjusted by the provided vector offset.


## Arguments

| Name | Type | Description |
|---|---|---|
| `offset` | `vector` | Offset relative to the prim's position, expressed in local coordinates. |

**Returns:** `number`
