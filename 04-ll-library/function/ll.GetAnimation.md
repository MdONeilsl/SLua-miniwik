# `ll.GetAnimation`

```lua
ll.GetAnimation(avatar: uuid) -> string
```

For the given avatar, this function returns the name of the locomotion animation that is currently active.

## Arguments

| Name | Type | Description |
|---|---|---|
| `avatar` | `uuid` | UUID of the avatar in the same region. |

**Returns:** `string`

## Definition fields

| Field | Value |
|---|---|
| `energy` | `10.0` |
| `sleep` | `0.0` |
| `categories` | `avatar`, `avatar_animation`, `permissions` |
